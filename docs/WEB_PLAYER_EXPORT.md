# 網頁播放器輸出 / Web player export

主畫面及編輯器的「輸出…」選單提供「MP4 影片」及「網頁播放器」。錄影、保存或其他輸出進行中仍依既有狀態限制操作；剪輯有未儲存變更時，先完成儲存選擇。

- MP4 影片：選擇檔名及位置，既有同名檔不覆寫。
- 網頁播放器：選擇存放位置，建立 `OpenCam_專案名稱_時間_唯一識別碼` 資料夾。每次輸出為新資料夾，保留原始 MKV。
- 停止錄影後自動輸出的既有設定仍產生 MP4；網頁播放器由使用者手動選擇。

```text
OpenCam_專案名稱_時間_唯一識別碼/
├── index.html
├── media.mp4
└── opencam-player.js
```

雙擊 `index.html` 可使用影片底部的整合控制列：播放／暫停、進度、靜音／音量、倍速、寬螢幕及全螢幕。播放閒置三秒淡出，暫停、指標移入、觸碰或焦點進入會顯示；控制項具有焦點時不隱藏。寬螢幕暫時隱藏章節索引，再按一次還原。全螢幕包含控制列；若瀏覽器拒絕原生全螢幕，改用頁面內滿版，可按 Esc 或全螢幕按鈕退出。無 JavaScript 或資料無法載入時仍保留原生影片控制列。

標題區採 OpenCam 藍灰色系的輕巧白色卡片。章節列顯示起始時間及片段總長度，超出索引高度時在清單內捲動。整個資料夾必須一起搬移；也可整包上傳靜態網站。播放器不依賴 CDN、外部字型、網路 API、JSON fetch 或 EverCam 的 config.js／js／css 目錄。index.html 及 JS 註解均註明 OpenCam 與專案網址。實際離線播放仍需支援 H.264／AAC 的瀏覽器；此功能自 v0.3.3 加入，實際瀏覽器視覺／播放驗收仍待完成。

章節使用最終保存的片段清單：裁減後的保留長度、拖曳後的順序及使用者設定名稱。合併後是單一章節，群組內未合併的片段仍各有章節。時間為最終影片中的秒數，不是來源 MKV 的原始 PTS。

## Video-to-Subtitle 識別契約

`opencam-player.js` 為 UTF-8，具有固定註解及唯一全域資料指派：

```javascript
// Generated by OpenCam — https://github.com/kaoshou/OpenCam
window.OpenCamPlayerData = {
  "format": "opencam.web-player",
  "schemaVersion": 1,
  "generator": {
    "name": "OpenCam",
    "version": "0.3.4",
    "projectUrl": "https://github.com/kaoshou/OpenCam"
  },
  "entry": "index.html",
  "media": "media.mp4",
  "title": "專案名稱",
  "chapters": [
    { "id": "片段 UUID", "title": "介紹", "start": 0, "end": 12.5 }
  ]
};
```

外部工具應檢查固定檔名、`format` 及支援的 `schemaVersion`，並確認 index.html／media.mp4 存在。`generator.version` 是產出程式版本，不是檔案格式版本；範例的 0.3.4 僅表示目前來源版本。

讀取時只擷取 `window.OpenCamPlayerData =` 後的 JSON 資料、移除最後的分號，以 JSON parser 解析。不要以 eval 執行來路不明的 JS；實際產生器只輸出嚴格 JSON 指派，不含額外程式。名稱含 HTML／JS 特殊字元時以安全 JSON 編碼保存。

輸出沿用原 MP4 的驗證與快速／精剪選擇，不因網頁格式額外編碼第二次。完成影片與 JS 後才發布入口頁面；取消／失敗清理本次已知檔案，可能留下空的獨立資料夾，既有輸出與原始素材保留。

## 多語字幕（v0.3.4）

編輯器「附加影片字幕」可選取或拖放 SRT／VTT。依檔名判斷 zh-TW、en、ko 等語言，無法判斷時先使用繁體中文（台灣），可手動更改。預設字幕優先繁體中文；沒有該軌時使用第一軌並提示，也可在字幕卡片勾選「設為預設」（單選），不使用上方下拉選單。相同語言可替換或保留多軌。

字幕複製至專案 `subtitles/<唯一識別碼>.srt|.vtt`，同名檔不覆蓋。最多32軌，每檔10 MiB、100,000則字幕、每則10,000字；支援 UTF-8 及具有 BOM 的 UTF-16。取消匯入可能留下未引用資產，以免誤刪復原／重做需要的資料。套用只修改編輯狀態，仍須儲存專案。**保存字幕會升為專案格式4，已發布的舊版0.3.3無法開啟；請先備份。** 無字幕專案不因此自動升級。

一般與全螢幕預覽都可選語言或關閉字幕，調整大小、配色、背景透明度及位置。預覽選擇不改變專案預設字幕。字幕時間依最終影片時間軸；裁剪、重排或續錄後須確認同步，不自動改寫時間。可在附加視窗確認新基準，或輸出時選擇此次附加／不附加／取消。

網頁仍只有三個固定檔案；`opencam-player.js` 的可選 `subtitles` 欄位包含 `defaultTrackId` 和 `tracks`，每軌含 `id`、`language`、`label`、`cues`，每則為秒數 `start`／`end` 與純文字 `text`。字幕不燒入 MP4、不額外重編碼。CC 選單預設開啟指定語言，可關閉及即時改變外觀；瀏覽器儲存偏好不可用時仍可操作。字幕不執行 HTML／樣式指令，原生畫中畫字幕不在支援範圍。離線瀏覽器、觸控及 Windows 原生視窗仍待人工驗收。

### 逐字稿搜尋

網頁右側可切換「章節／逐字稿」。逐字稿語言與影片字幕開關獨立；即使關閉畫面字幕仍可搜尋、閱讀。使用已附加的字幕，不辨識語音或連線到外部服務。輸入文字後以不區分大小寫的純文字搜尋，顯示結果數與關鍵字標示；點擊一列跳至開始時間，保持原本播放／暫停狀態。

預設「跟隨播放」會顯示當前字幕，搜尋期間暫停跟隨，也可關閉開關自行閱讀。每次顯示100列，可載入更多；播放跳至較遠時間時跟隨切換到對應批次，不一次建立全部字幕元素。固定區域內捲動，手機版也限制清單高度。沒有字幕時顯示說明。依然維持三檔案結構，標題摘要只顯示長度與章節數；頁尾及原始碼來源註記保留。

側欄整體高度跟隨播放器並受視窗高度限制，切換逐字稿或載入更多列不撐高页面，超出內容在清單內捲動。應用程式的字幕語言選單依目前中英文介面顯示名稱與括號代碼；繁體中文介面使用「繁體中文（台灣） (zh-TW)」與「簡體中文（中國大陸） (zh-CN)」。網頁字幕及逐字稿選單只顯示語言名稱與代碼，不顯示匯入檔名；軌道識別及專案內原始檔名資訊不變。

## English

### 閱讀與下載 / Reading and download

「閱讀設定」使用小型箭頭文字按鈕，展開時箭頭向下。頁首按 Tab 可依序前往播放器、章節、逐字稿；頁面下方「鍵盤操作說明」也提供這三個入口。跳到章節或逐字稿會還原被寬螢幕隱藏的側欄並將焦點移到對應分頁。沒有字幕仍可到逐字稿區閱讀說明。

播放快捷鍵僅在影片區取得焦點時生效：Space 播放／暫停、左右鍵跳轉5秒、F 切換全螢幕；搜尋、滑桿與選單保留原生鍵盤操作，Ctrl／Alt／Command 組合鍵不觸發影片快捷鍵。章節列啟動後跳轉並播放；逐字稿列保留目前播放／暫停狀態。鍵盤說明依適用位置分組，手機直向排列。

The compact Reading settings text button indicates its expanded state with an arrow. Three keyboard skip links and the links inside Keyboard help focus the player, Chapters or Transcript; sidebar destinations restore wide-screen layout. Playback shortcuts work only on the focused video area. Form controls and browser modifier shortcuts keep their normal behavior. Help groups identify where each key applies and stack on small screens.

逐字稿區預設保留語言與搜尋；按右上角「閱讀設定」開啟單層設定浮層，包含跟隨播放、閱讀字級、行距、背景對比、重設與下載。浮層不擠壓逐字稿，可按關閉、Esc 或點外側關閉；窄螢幕內部捲動。CC 字幕外觀仍獨立設定，不改影片區版面。下載按鈕產生所選語系的**完整** HTML／UTF-8 TXT，與搜尋及100列批次無關；時間標記選填，章節依最終影片時間排序。HTML 只含安全編碼後的文字與內嵌排版，不含影片、腳本或外部資源，可離線閱讀／列印。瀏覽器不支援下載時顯示提示；不回退到執行匯入的 HTML。

Playback follow pauses DOM paging/scrolling while a transcript row or its list owns keyboard focus. CC has an explicit close button, Escape focus return, and closes when keyboard focus leaves it. Tabs support arrows/Home/End; typing in form fields never triggers video shortcuts. The website/guide support skip-to-main focus and responsive navigation without replacing the established design.

依 [W3C 逐字稿指引](https://www.w3.org/WAI/media/av/transcripts/)，可由字幕製作逐字稿，但必要的說話者、非語音聲音與視覺資訊仍需作者核對補充。程式不推測或自動宣稱內容等價。介面以 WCAG 2.2 AA 為檢查目標；自動檢查不取代螢幕閱讀器、實際使用者與內容審查，也不等於正式無障礙認證。

Both export menus offer **MP4 video** and **Web player**. MP4 retains the file picker. Web player asks for a parent location and creates a unique folder with the three fixed filenames above. Automatic export on recording stop continues to produce MP4.

Move the entire folder or upload it to a static site. Playback uses local files and requires an H.264/AAC-capable browser. Chapters follow the final saved logical clip order, names and retained durations. Merged clips form one chapter; grouped but unmerged clips remain separate chapters.

External tools should verify `opencam-player.js`, `format: "opencam.web-player"`, supported `schemaVersion`, and the entry/media files. Parse the strict JSON assignment without evaluating JavaScript. Generator version and schema version are independent. Original MKV media and existing packages are never overwritten.

v0.3.4 subtitle support: select or drop SRT/VTT files in the editor, choose inferred/manual languages and the default track. Unique project-owned paths prevent identical filenames from overwriting each other. Apply edits the draft; save is explicit. Saving subtitles upgrades project format to4, which released0.3.3 cannot open: back up first. Preview/fullscreen language and appearance choices do not change the authored default. Timeline changes require a subtitle-sync decision before web export; no automatic retiming or MP4 burn-in occurs. Optional subtitle data is embedded in `opencam-player.js`; the package still has three files. Native picture-in-picture captions are not supported. Offline browser, touch and Windows-native visual validation remain manual.

Choose the default using the radio control on each subtitle card. The Web sidebar now switches between chapters and transcript, with independent transcript language, case-insensitive plain-text search, keyword highlighting and click-to-seek preserving play/pause state. Follow-playback is optional and suspended during search. Rows render in batches of100 inside a scrolling panel; no transcription service or additional package files are required.
