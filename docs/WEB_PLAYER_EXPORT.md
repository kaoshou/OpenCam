# 網頁播放器輸出 / Web player export

主畫面及編輯器的「輸出…」選單提供「MP4 影片」及「網頁播放器」。錄影、保存或其他輸出進行中仍依既有狀態限制操作；剪輯有未儲存變更時，先完成儲存選擇。

- MP4 影片：選擇檔名及位置，既有同名檔不覆寫。
- 網頁播放器：選擇存放位置，建立 `OpenCam_專案名稱_時間_唯一識別碼` 資料夾。每次輸出為新資料夾，保留原始 MKV。
- 停止錄影後自動輸出的既有設定仍產生 MP4；網頁播放器由使用者手動選擇。

```text
OpenCam_專案名稱_時間_唯一識別碼/
├── index.html
├── media.mp4
└── opencam-player.js
```

雙擊 `index.html` 可使用影片底部的整合控制列：播放／暫停、進度、靜音／音量、倍速、寬螢幕及全螢幕。播放閒置三秒淡出，暫停、指標移入、觸碰或焦點進入會顯示；控制項具有焦點時不隱藏。寬螢幕暫時隱藏章節索引，再按一次還原。全螢幕包含控制列；若瀏覽器拒絕原生全螢幕，改用頁面內滿版，可按 Esc 或全螢幕按鈕退出。無 JavaScript 或資料無法載入時仍保留原生影片控制列。

標題區採 OpenCam 藍灰色系的輕巧白色卡片。章節列顯示起始時間及片段總長度，超出索引高度時在清單內捲動。整個資料夾必須一起搬移；也可整包上傳靜態網站。播放器不依賴 CDN、外部字型、網路 API、JSON fetch 或 EverCam 的 config.js／js／css 目錄。index.html 及 JS 註解均註明 OpenCam 與專案網址。實際離線播放仍需支援 H.264／AAC 的瀏覽器；此功能自 v0.3.3 加入，實際瀏覽器視覺／播放驗收仍待完成。

章節使用最終保存的片段清單：裁減後的保留長度、拖曳後的順序及使用者設定名稱。合併後是單一章節，群組內未合併的片段仍各有章節。時間為最終影片中的秒數，不是來源 MKV 的原始 PTS。

## Video-to-Subtitle 識別契約

`opencam-player.js` 為 UTF-8，具有固定註解及唯一全域資料指派：

```javascript
// Generated by OpenCam — https://github.com/kaoshou/OpenCam
window.OpenCamPlayerData = {
  "format": "opencam.web-player",
  "schemaVersion": 1,
  "generator": {
    "name": "OpenCam",
    "version": "0.3.3",
    "projectUrl": "https://github.com/kaoshou/OpenCam"
  },
  "entry": "index.html",
  "media": "media.mp4",
  "title": "專案名稱",
  "chapters": [
    { "id": "片段 UUID", "title": "介紹", "start": 0, "end": 12.5 }
  ]
};
```

外部工具應檢查固定檔名、`format` 及支援的 `schemaVersion`，並確認 index.html／media.mp4 存在。`generator.version` 是產出程式版本，不是檔案格式版本；範例的 0.3.3 僅表示目前來源版本。

讀取時只擷取 `window.OpenCamPlayerData =` 後的 JSON 資料、移除最後的分號，以 JSON parser 解析。不要以 eval 執行來路不明的 JS；實際產生器只輸出嚴格 JSON 指派，不含額外程式。名稱含 HTML／JS 特殊字元時以安全 JSON 編碼保存。

輸出沿用原 MP4 的驗證與快速／精剪選擇，不因網頁格式額外編碼第二次。完成影片與 JS 後才發布入口頁面；取消／失敗清理本次已知檔案，可能留下空的獨立資料夾，既有輸出與原始素材保留。

## English

Both export menus offer **MP4 video** and **Web player**. MP4 retains the file picker. Web player asks for a parent location and creates a unique folder with the three fixed filenames above. Automatic export on recording stop continues to produce MP4.

Move the entire folder or upload it to a static site. Playback uses local files and requires an H.264/AAC-capable browser. Chapters follow the final saved logical clip order, names and retained durations. Merged clips form one chapter; grouped but unmerged clips remain separate chapters.

External tools should verify `opencam-player.js`, `format: "opencam.web-player"`, supported `schemaVersion`, and the entry/media files. Parse the strict JSON assignment without evaluating JavaScript. Generator version and schema version are independent. Original MKV media and existing packages are never overwritten.
