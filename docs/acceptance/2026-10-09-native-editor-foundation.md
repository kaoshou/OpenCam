日期：2026-10-09（Asia/Taipei）

**狀態：部分完成；不是可發布或完整可用的編輯器。**

## 已實作與測試

- 中英文入口改為「錄影專案／Recording project」，不再出現開發預覽主標題；原快速錄影入口與設定沿用。
- 非破壞性剪輯核心：裁短／還原保留區間、分割、刪除、跨片段刪範圍、整組移動、群組／解除群組、復原／重做。
- 保存及認證 IPC 接線：同 operationId 重送不重複剪輯、舊 revision 拒絕、保存失敗保留 dirty state 與歷史。這些核心操作尚未完整接到時間軸手勢。
- PTS 時間映射：非零／負來源起點、半開區間、分數累加、超出可表示時間時明確拒絕。不是已完成 VFR 逐格播放器。
- 原生工作區初步區域配置：左清單／中預覽區／右屬性／下時間軸區，1440×900、1280×720、1024×640 自動收合及手動面板切換；保留原 inspector 的捲動與右側文字避讓。
- 預覽區與時間軸区尚未連接播放器或媒體快取，明示未接線；沒有示範投影片、假波形或假輸出按鈕。不以這個中間畫面要求使用者重新確認版型。

## 測試證據

入口測試：先重現兩語言錯誤標題，再通過 4 項入口測試。

剪輯核心：11 項新測試先對空實作失敗；加上微小選區與非連續群組兩項 RED→GREEN。完整核心 139 項通過。剪輯 IPC 的遺失回覆與保存失敗兩項先重現缺功能，再通過；該次完整 Media 376 項通過、13 項平台／裝置測試略過。合計 515 項通過、13 項略過。

版面／互動聚焦測試 15 項通過。headless 的原始預設 client size 固定 1024×768，不能只設 Width／Height 冒充三種尺寸；現測試透過測試專用反射發送 Avalonia 原生 resize callback，並斷言 ClientSize。不是實機高 DPI 或 Windows 驗收。

獨立唯讀審查指出兩項 Important，均先以回歸測試重現：

- 1/60 時基分割前後在 166666／333333 ticks 的來源 PTS 不一致：改為保留每段精確有理數起點，可表示的 ticks 接點統一向上取整；不讓單純分割提早選到下一格。
- 刪除群組單一成員錯刪整組：Remove 僅刪指定成員，群組只影響移動；首／中／尾三種位置及 Undo 一併測試。

擴充後審查回歸先出現 5 FAIL／2 PASS；修正後完整回歸為 Core 146 PASS、Media 387 PASS／13 SKIP，合計 **533 PASS／13 SKIP、0 FAIL**。無建置警告或錯誤；略過項目仍需實機驗收。

FFmpeg pipe 探針的定位、連續取消與 Stop 結果詳見 [選型紀錄](../adr/recording-project-preview-engine.md)。未通過整體後端門檻，工具必須回傳非零，不能把部分 PASS 當選型通過。

### 後續本機驗證

- 新增 macOS 綁定 FD 探針，使用 7.1.2：非零／負 PTS、60 FPS、VFR 皆以實際畫格 SHA-256 核對；來源路徑替換、來源 SHA 不變、連續取消、停止回收子程序、壞檔／程序失敗／輸出限額均通過。
- 獨立原生音訊探針確認真實輸出裝置收到非零樣本、時鐘前進；停止後樣本不增加，重啟及第二次停止也同樣觀察。這不是整合播放器或續錄隔離驗收。
- 兩小時 64×36／30 FPS／GOP 300 測資在尾端定位 p95 12.4ms；不能外推為 1080p 或 200 片段完整編輯器效能。
- 清單改為分頁取得、完整核對後一起呈現，能載入 200 片段並在刷新時保留第 151 段選取；拒絕跨專案／revision／不符數量／重複 ID／未確認的資料。關閉專案清除舊片段。
- 長中英文名稱／深淺色 headless 測試先重現 90～157px 高片段名稱及標題覆蓋操作，修正兩行省略與完整提示後通過；實際虛擬化清單捲動後選取不變。這不是實機 DPI 驗收。
- 獨立審查發現背景安全停止查詢在多頁載入時提早開放編輯；延遲第二頁測試先 FAIL，修正 busy 期間後 PASS。第二次音訊停止的觀察亦依審查補強。
