# OpenCam v0.1.0

## 繁體中文

- 首次公開提供 Windows 與 macOS 螢幕錄影，支援全螢幕、指定螢幕及自訂區域。
- 系統聲音與麥克風可分別開關，支援游標效果及硬體／軟體編碼。
- 使用 MKV 保存錄影工作檔，停止後封裝 MP4；提供中斷救援與磁碟空間提醒。
- 介面可切換繁體中文與英文。

## English

- First public release for Windows and macOS, with fullscreen, monitor and custom-region recording.
- Control system audio and microphone independently, choose cursor effects, and use hardware or software encoding.
- Record to MKV working files and package MP4 after stopping, with interruption recovery and disk-space reminders.
- Switch between Traditional Chinese and English.
