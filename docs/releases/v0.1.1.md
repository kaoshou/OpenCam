# OpenCam v0.1.1

## 繁體中文

- 新增 macOS 系統聲音錄製與麥克風混音。
- 改善 macOS 螢幕選擇、錄影權限提示與自訂區域的透明顯示、移動及縮放。
- 暫停後修改聲音與游標設定，會套用到下一段錄影。
- 改善 macOS 錄影啟動、畫面尺寸與應用程式圖示；可使用系統檔案管理員開啟錄影位置。

## English

- Added macOS system-audio capture and microphone mixing.
- Improved macOS display selection, permission prompts, and transparent, movable, resizable recording regions.
- Audio and cursor changes made while paused now apply to the next recording segment.
- Improved macOS startup, capture dimensions and application icons, and opening recording locations in the system file manager.
