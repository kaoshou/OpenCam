# OpenCam v0.2.0

## 繁體中文

- 新增螢幕辨識按鈕，在已連接顯示器上顯示編號，方便選擇錄影螢幕。
- 自訂區域選取框保持透明，支援拖曳移動與調整大小。
- 錄影狀態區分別顯示系統聲音與麥克風的即時音量波形。
- 開始錄影後鎖定固定設定，暫停時仍可調整音訊與游標；關閉視窗時提供錄影保護提示。

## English

- Added display identification with numbered labels on connected monitors.
- Added transparent, movable and resizable custom recording regions.
- Show separate live level waveforms for system audio and microphone.
- Lock fixed settings after recording starts while allowing audio/cursor changes during pause, with close protection for active recordings.
