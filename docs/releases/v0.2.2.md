# OpenCam v0.2.2

## 繁體中文

- 錄影狀態區新增工作檔、畫面、編碼器與音源狀態提醒，方便察覺錄製異常。
- 改善錄影啟動的狀態判斷與錯誤提示。
- 統一應用程式與安裝包版本資訊，改善新版 macOS 的圖示相容性。

## English

- Added recording-health feedback for working files, frames, encoders and audio sources.
- Improved recording-start status detection and error messages.
- Aligned application/package version information and improved icon compatibility with newer macOS versions.
