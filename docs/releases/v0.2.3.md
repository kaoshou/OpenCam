# OpenCam v0.2.3

## 繁體中文

- 加強本機錄影控制通訊的身分驗證與重播防護。
- 加強中斷救援的路徑與防覆寫保護，以快照處理來源並保留原始 MKV。
- 改善特殊檔名的媒體工具參數處理。
- macOS 音訊改用匿名管線，保留系統聲音、麥克風混音及波形顯示。
- 修正「關於本程式」版本標籤的空白綠框。

## English

- Strengthened authentication and replay protection for local recorder control.
- Strengthened recovery-path and overwrite protection, processing snapshots while retaining original MKVs.
- Improved media-tool argument handling for special filenames.
- Switched macOS audio transport to anonymous pipes while retaining system/microphone mixing and level waveforms.
- Fixed the empty green version badge in About.
