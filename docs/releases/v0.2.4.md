# OpenCam v0.2.4

## 繁體中文

- 錄影狀態區顯示實際使用的編碼器與 CPU 備援原因。
- 改善編碼器偵測與快取；暫停／繼續使用已確認的編碼器，維持分段相容性。
- 改善啟動失敗處理，修正 Windows 錄影參數衝突，避免失敗片段混入救援結果。
- 下載檔名加入版本、平台與架構，方便辨識 Windows x64 與 macOS Apple Silicon 套件。

## English

- Show the actual recording encoder and the reason for CPU fallback.
- Improved encoder detection/caching and retained the confirmed encoder across pause/resume for compatible segments.
- Improved startup-failure handling, fixed conflicting Windows recording arguments, and excluded failed attempts from recovery output.
- Download filenames now identify the version, platform and architecture: Windows x64 or macOS Apple Silicon.
