# OpenCam v0.2.5

## 繁體中文

- Windows 新增可自行啟用的 Desktop Duplication 擷取選項；GDI 維持預設。
- 狀態區顯示實際擷取方式與備援原因，不支援的顯示器配置自動使用 GDI。
- 支援相容顯示器的整個螢幕或螢幕內選區；多 GPU、旋轉及跨螢幕選區使用 GDI。
- 改善擷取初始化失敗與桌面變更的處理，保留已錄製工作檔。

## English

- Added an opt-in Windows Desktop Duplication capture option; GDI remains the default.
- Show the active capture method and fallback reason, using GDI for unsupported display layouts.
- Support whole monitors or regions within compatible displays; multiple GPUs, rotation and cross-monitor regions use GDI.
- Improved capture-initialization and desktop-change handling while retaining recorded working files.
