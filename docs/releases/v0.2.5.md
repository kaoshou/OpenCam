# OpenCam v0.2.5

## English

- Adds an opt-in Windows Desktop Duplication capture mode to try to reduce live cursor flicker. Enable **Settings → Windows screen capture → Modern capture (experimental)**. GDI remains the default.
- Shows the actual capture backend and fallback reason. Unsupported or ambiguous layouts use GDI, including multiple hardware GPUs (even headless GPUs), rotated outputs and cross-screen regions. Multiple monitors on one supported GPU are allowed.
- Recognized DDA initialization errors can retry GDI once before the first valid segment. Confirmed segments keep their backend; output/desktop loss triggers a safe stop while preserving working files. Unknown errors do not trigger blind retries.
- macOS capture and the existing audio input implementation are unchanged.

### Downloads

- `OpenCam_v0.2.5_Windows_x64_Setup.exe` — Windows x64 installer.
- `OpenCam_v0.2.5_Windows_x64_Portable.zip` — Windows x64 portable package.
- `OpenCam_v0.2.5_macOS_arm64.dmg` — macOS 13+ Apple Silicon, not Intel Mac.

Release binaries are built by GitHub Actions from the release commit, not local packages.

### Limitations

The new capture option remains experimental. Automated tests and successful packaging do **not** establish that affected Windows hardware no longer flickers or uses less CPU. Real COM/driver behavior, long-duration A/V synchronization, live audio/GUI acceptance and interruption recovery still require manual validation. Multiple-GPU DDA, rotation and zero-copy are not supported. Existing signing and Windows FFmpeg corresponding-source audit limitations remain; this is not a claim that all security or licensing issues are resolved. See the [capture verification report](https://github.com/kaoshou/OpenCam/blob/v0.2.5/docs/verification/2026-09-30-windows-capture.md).

## 繁體中文

- 增加可自行啟用的 Windows Desktop Duplication 擷取模式，嘗試改善錄影當下的實體游標閃爍。於「設定 → Windows 畫面擷取 → 新版擷取（測試）」啟用；預設仍為 GDI。
- 顯示實際擷取方式與回退原因。多硬體 GPU（包含未接螢幕者）、旋轉、跨螢幕選區或不明對應使用 GDI；支援同一適用 GPU 上的多台螢幕。
- 首個有效片段前，已知 DDA 初始化錯誤可用新檔名備援 GDI 一次；成功後固定擷取方式，輸出或桌面失效時安全停止並保留工作檔。未知錯誤不盲目重試。
- 不更換 macOS 擷取及既有音訊輸入實作。三種下載檔均包含版本號與平台資訊，由發布提交的 GitHub Actions 建置，非本機封裝。

### 驗收限制

新版擷取仍屬實驗功能，**不宣稱已證實游標閃爍消失或 CPU 降低**。自動化測試與封裝成功不能取代受影響 Windows 的驅動、長時間音畫同步、收音／GUI 與中斷救援實機驗收。多 GPU DDA、旋轉與零拷貝尚不支援。既有簽章及 Windows FFmpeg 對應原始碼核對限制仍保留，不代表所有安全或授權問題已解決。詳見[驗證報告](https://github.com/kaoshou/OpenCam/blob/v0.2.5/docs/verification/2026-09-30-windows-capture.md)。
