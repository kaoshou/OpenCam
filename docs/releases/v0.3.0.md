# OpenCam v0.3.0

## 繁體中文

- 新增可命名、重開與繼續追加錄影的專案。
- 編輯器提供片段排序、修剪、分割、刪除範圍、復原／重做與改名。
- 片段可調整音量、靜音、淡入淡出、裁切、縮放與位置。
- 預覽提供聲音開關、畫質選擇、可調整大小及全螢幕。
- 儲存專案與 MP4 輸出分開，可選擇停止後自動輸出或稍後手動輸出。
- 剪輯保留原始 MKV；相容完整片段可快速輸出，剪輯或效果使用重新轉檔。

## English

- Added named, reopenable projects that support appending further recordings.
- The editor supports clip reordering, trimming, splitting, range deletion, undo/redo and renaming.
- Adjust clip volume, mute, fades, crop, scale and position.
- Preview offers sound on/off, quality selection, resizing and fullscreen.
- Project saving is separate from MP4 export, with automatic export on stop or manual export later.
- Editing preserves original MKVs; compatible complete clips support fast export, while edits/effects use rendering.
