## 繁體中文

- 錄影以可重開的命名專案保存。沒有專案時，開始錄影先確認名稱；已有或重新開啟的專案可追加片段。主畫面集中新增／開啟專案與目前內容摘要。
- 停止後自動輸出 MP4 是每個專案的設定，預設開啟；關閉後停止只保存內容，稍後可手動輸出。既有已驗證輸出可重用：手動再次輸出相同內容時，可開啟既有成品或重新輸出。
- 編輯器支援片段清單及時間軸拖曳排序、修剪、分割、刪除片段／範圍、復原／重做，以及專案與片段改名。片段屬性包括音量、靜音、淡入淡出、裁切、縮放與位置。
- 預覽加入聲音開／關、畫質選擇、可調整預覽區與全螢幕。聲音開關不改變輸出音軌，沒有獨立預覽音量滑桿；原始畫質預覽受影格記憶體限制。
- 明確區分儲存的專案與復原草稿。未儲存修改的切換／關閉流程提供儲存、捨棄或取消；重開可選擇是否復原中斷的草稿。儲存專案不等於已輸出最新 MP4。
- 錄影時禁止進入編輯器、新增或開啟專案；暫停保存片段後才可編輯。返回主畫面保留專案，繼續錄影會收起編輯器。
- 原始 MKV 不因剪輯、改名或 MP4 輸出而覆寫／刪除。請保留整個專案資料夾，不能只搬移 `project.opencam`。
- MP4 輸出依素材證據選擇路徑：相容完整片段可保留影片編碼；音訊必要時轉碼。修剪、效果、不相容串流或無法確認封包時序會重新渲染。多段 AAC 若需要連續正規化，現階段使用精確渲染後備路徑，不宣稱所有輸出即時或無損。

## English

- Recordings live in named, reopenable projects. Start confirms a name when no project is open; existing and reopened projects receive appended clips. New/Open project actions and the current-project summary live on the home screen.
- Auto-export MP4 on stop is a per-project option, on by default. Turn it off to save content only and export manually later. A verified existing export can be reused: manual export of unchanged content offers opening the existing result or exporting again.
- The editor supports drag reordering in the clip list and timeline, trimming, splitting, deleting clips/ranges, undo/redo, and project/clip naming. Clip properties include volume, mute, fades, crop, scale and position.
- Preview offers sound on/off, quality selection, a resizable area and fullscreen. Preview mute does not change exported audio, and there is no separate preview volume slider. Original-resolution preview is subject to a frame-memory limit.
- Explicitly saved projects differ from recovery drafts. Switching/closing with unsaved edits offers Save, Discard or Cancel; reopening can restore interrupted drafts. Saving a project does not export the latest MP4.
- Active recording blocks editor entry and project creation/opening; saved paused segments can be edited. Returning home retains the project, and resuming capture hides the editor.
- Editing, renaming and export do not overwrite/delete original MKVs. Retain the entire project folder, not just `project.opencam`.
- MP4 export chooses a path from source evidence. Compatible complete clips may preserve encoded video, with audio conversion when needed. Trims, effects, incompatible streams or unavailable packet timing require rendering. Multi-segment AAC that needs continuous normalization currently falls back to the exact renderer. Export is not always instant or lossless.

### Outstanding release gates

- Windows device acceptance for native recording, system audio/microphone, pause/resume, editor audiovisual preview, save/reopen/append, export and interrupted-recording recovery, including long A/V synchronization.
- Nine targeted tests pass for the bounded AAC priming/padding fix: affected clips use normalized re-encoding instead of unsafe direct concatenation. The full Media suite reports 651 passed, 20 skipped and 0 failed; four optional audio-helper tests skipped because their helper was not provided. Skips are not passes. This does not resolve all AAC or hardware issues, and clean-snapshot solution verification completed: Core 205 passed; Media 651 passed, 20 skipped, 0 failed.
