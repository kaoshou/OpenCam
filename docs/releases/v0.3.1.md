# OpenCam v0.3.1 — 輸出效率與首頁空間 / Export efficiency and home layout

## 繁體中文

- 首頁預設高度調整為 820，依螢幕工作區與縮放比例限制高度，保留設定區捲動，讓專案資訊增加後的下方設定更容易看見。
- 相容、完整且未剪輯的多段錄影，需要音訊正規化時，保留 H.264 影片編碼、對齊各片段音訊後只編碼一次 AAC，避免不必要的影片重新編碼。單段與可直接複製的輸出路徑保留。
- 輸出時區分素材檢查、複製、音訊轉換、完整轉檔及驗證。剪輯、效果或不相容素材仍可能需要完整轉檔，不保證瞬間輸出。
- 發布 MP4 前核對影片封包內容、播放時間位置、片段邊界與音訊長度。不相容時安全退回完整轉檔；取消或 I/O 失敗不直接重試轉檔。原始 MKV 不覆寫、不刪除。
- 音訊正規化會使用暫時 PCM／影片檔，需額外磁碟空間，完成或取消後清理；不建立永久預處理素材。

### 驗證與限制

本機 Release 回歸為 Core 205、Media 677 通過，19 略過，0 失敗；包含 100 片段、B-frame、可變影格率、逐封包時間、接點聲音標記及取消／失敗清理。此數據不等於 Windows 原生實機或完整 Release Gate 驗收。使用者在知悉待驗收項目後要求發布，未將待驗收項目標示通過。

Windows 實機／長時間音畫同步、實際磁碟耗盡測試仍待完成；macOS 原生畫面檢查遇到 RenderTimer -6661，無法完成視覺驗收。Windows FFmpeg 完整對應原始碼核對尚未完成；套件未簽章，macOS 未公證。未宣稱所有安全、授權、硬體問題均已解決。請保留專案及原始素材備份。

## English

- Increase the home window's default height to 820 logical pixels, bounded by the screen work area and scaling. Retain settings scrolling and user resizing.
- Compatible whole, unedited multi-segment recordings can retain encoded H.264 while normalizing per-clip audio and encoding AAC once. Existing single-source and direct-copy routes remain available.
- Distinguish inspection, copying, audio conversion, rendering and verification in export progress. Edits, effects or incompatible media may still require rendering; instant export is not promised.
- Verify packet payloads, presentation offsets, segment boundaries and audio coverage before publishing MP4. Recognized incompatibility falls back to rendering; cancellation and I/O failures do not. Original MKVs are never overwritten or deleted.
- Audio normalization uses temporary PCM/video staging and additional disk space, cleaned up on completion or cancellation; no persistent pre-processing cache is created.

### Verification and limitations

Local Release regression: Core 205 and Media 677 passed, 19 skipped, zero failures. Coverage includes 100 segments, B-frames, VFR, packet timing, audio join markers and cancellation/failure cleanup. These results are not Windows device or complete Release Gate acceptance. Publication was requested with outstanding acceptance items disclosed; pending checks are not labeled passed.

Native Windows/long-duration A/V acceptance and physical disk-exhaustion tests remain pending. Native macOS visual inspection was blocked by RenderTimer -6661. Complete corresponding-source verification for Windows FFmpeg remains pending. Packages are unsigned and macOS notarization is not provided. This is not a claim that all security, licensing or hardware issues are resolved. Keep backups of projects and original recordings.
