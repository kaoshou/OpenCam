# OpenCam v0.3.1

## 繁體中文

- 增加主畫面可用高度，讓專案資訊與下方設定更容易查看。
- 改善相容、未剪輯多段錄影的輸出：需要音訊正規化時保留原影片編碼，只轉換音訊。
- 輸出狀態更清楚區分素材檢查、複製、音訊轉換及完整轉檔。
- 改善 Windows 安裝包內隨附媒體工具的提供。

## English

- Increased usable home-window space so project information and lower settings are easier to view.
- Improved export of compatible unedited recordings by retaining encoded video when only audio needs normalization.
- Clearer export status distinguishes inspection, copying, audio conversion and full rendering.
- Improved delivery of the bundled media tools in Windows packages.
