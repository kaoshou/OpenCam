# OpenCam v0.3.10

## 繁體中文

- 錄前範圍預覽改由既有平台擷取管線直接輸出縮小後的 RGBA 影格，省去 H.264 編碼、MKV 封裝與第二次解碼。保留既有螢幕／區域、游標與音源設定；正式錄影及五秒試錄仍使用原本的保存管線。
- 預覽輸出為等比例置入 960×540、10 FPS，只保留最新完整影格；介面一次只發送一個影格請求，不排隊播放舊影格。實際更新速度與延遲仍依設備和負載，不保證固定毫秒或 30／60 FPS。
- 在既有錄影範圍文字後加上低調的「預覽非即時同步，僅供確認錄製範圍。」說明。
- 試錄按下後先顯示「啟動試錄中，請稍候…」，引擎確認啟動後才顯示「試錄中」並開始五秒計時；完成擷取後顯示準備回放狀態。繁體中文與英文同步更新。
- 保留取消、清理、操作身分及版本檢查、音源選擇與正式錄影啟動確認。未加入其他效能架構改造或新應用程式套件。
- 修正匯出已顯示終止狀態、背景工作卻尚未結束的短暫競態，避免取消後立即關閉專案仍被判定為匯出中；來源保護仍等工作真正結束。

### 相容性與限制

- 直接預覽確認擷取範圍與音量，不代表完整保存編碼器已實機驗收；請以五秒試錄及回放確認影片和聲音。
- Windows／macOS 原生預覽延遲、四種音源組合、GPU、游標、多螢幕／DPI 仍需實機驗收。原始影格傳輸增加資料量，本機合成／headless 測試不等於實機效能確認。
- 專案格式不變，字幕仍使用格式4，v0.3.3及以前不能開啟。請備份完整專案含重點附屬檔；字幕不燒入 MP4、不自動對時。
- 完整實體 Release Gate、長時間 A/V、macOS 視覺、實際磁碟耗盡、瀏覽器離線／觸控／全螢幕、浮窗擷取排除與背景快捷鍵未全部完成；歷史 Windows 心跳／快速輸出偶發問題不宣稱全部根治。
- 套件未具可信發行者簽章或 macOS 公證；Windows FFmpeg 完整對應原始碼核對仍待完成。依使用者授權發布，不代表全部可靠性、安全、授權或實機驗收已通過。既有示範圖保留真實版本標示。

## English

- Live preflight preview now receives scaled RGBA frames directly from the existing platform capture pipeline, removing H.264 encoding, MKV packaging and a second decoder. Existing screen/region, cursor and audio selections remain; formal recordings and five-second trials retain their saved-media pipeline.
- Preview output is aspect-fitted to 960×540 at 10 FPS, retaining only the latest complete frame. The UI keeps one frame request in flight rather than queueing old pictures. Actual rate and latency depend on hardware and load; no fixed millisecond or 30/60 FPS guarantee.
- Append a quiet note to the existing capture-area label: “Preview is delayed and intended only to confirm the capture area.”
- Trial recording first shows “Starting trial recording, please wait…”. Recording status and the five-second timer begin only after engine startup acknowledgement, followed by a preparing-playback phase. Traditional Chinese and English are updated together.
- Preserve cancellation, cleanup, operation identity/revision checks, selected audio inputs and formal recording-start acknowledgement. No additional performance architecture changes or application packages.
- Fix a race where export status became terminal before its worker completed, briefly rejecting project closure after cancellation. Source-owner protection still waits for actual worker completion.

### Compatibility and limits

- Direct preview checks the capture area and levels, not physical acceptance of the complete saved encoder path. Use the five-second trial and replay to verify video and sound.
- Native Windows/macOS preview latency, all four audio selections, GPU, cursor and multi-display/DPI behavior still require physical-device acceptance. Raw frames increase transfer volume; local synthetic/headless tests do not establish device performance.
- No project-format change. Subtitle projects retain format4, incompatible with v0.3.3 and earlier. Back up complete projects including bookmark sidecars; no MP4 subtitle burn-in or automatic retiming.
- The complete physical Release Gate, long A/V, macOS visuals, physical disk exhaustion, browser offline/touch/fullscreen, advisory capture exclusion and background shortcuts remain incomplete. Historical intermittent Windows heartbeat/fast-export issues are not claimed fully resolved.
- No trusted publisher signing or macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized, not complete reliability, security, licensing or device acceptance. Existing illustrations retain their actual version labels.
