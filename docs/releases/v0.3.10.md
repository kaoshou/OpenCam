# OpenCam v0.3.10

## 繁體中文

- 錄前範圍預覽改用直接輸出的縮小影格，減少編碼與解碼造成的延遲。
- 預覽採 960×540、10 FPS，只保留最新影格；範圍說明後附上「預覽非即時同步，僅供確認錄製範圍。」
- 試錄先顯示「啟動試錄中，請稍候…」，實際啟動後才顯示「試錄中」並開始五秒計時。
- 修正取消匯出後立即關閉專案，仍被誤判為匯出中的問題。

## English

- Preflight preview now uses directly emitted, scaled frames to reduce encoding/decoding delay.
- Preview uses 960×540 at 10 FPS and retains only the latest frame, with a note that it is for checking the capture area rather than real-time synchronization.
- Trials show a starting message first, then Recording and the five-second timer after capture begins.
- Fixed a project still appearing busy when closed immediately after canceling an export.
