# OpenCam v0.3.2

## 繁體中文

- 全螢幕預覽新增進度條，點選片段可跳至片段開頭。
- 新增前後片段合併，以及右鍵更名、群組、解除群組與刪除操作。
- 改善離開編輯器的儲存提醒，MP4 輸出可指定位置與檔名。
- 新增專案錄影總時間，暫停時可切換停止後自動輸出。
- 修正部分 MKV 缺少影格時間資訊時，短片段無法保存或停止失敗的問題。
- 合併片段使用專案格式 3；較舊版本無法開啟，請保留完整專案備份。

## English

- Added fullscreen seeking and jump-to-start when selecting a clip.
- Added adjacent-clip merging and context-menu rename, group, ungroup and delete actions.
- Improved save prompts when leaving the editor and destination/filename selection for MP4.
- Added project recording duration and allowed changing automatic export while paused.
- Fixed short-clip save and stop failures with MKVs missing frame-duration information.
- Merged clips use project format 3; older versions cannot open them, so retain complete project backups.
