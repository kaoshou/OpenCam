# OpenCam v0.3.2 — 剪輯操作與錄影穩定性 / Editor usability and recording fixes

## 繁體中文

- Windows 安裝程式及應用程式清單名稱統一為 OpenCam。
- 全螢幕預覽提供播放進度條；一般預覽保持簡潔。
- 片段支援與前／後片段合併、可復原編輯；左側清單提供更名、上下合併、上下群組、解除群組及刪除的右鍵選單。群組外框連續顯示，合併名稱不附加數量符號。
- 點選片段會將播放位置移至片段開頭。返回首頁與關閉編輯器都會處理未儲存變更；編輯器開啟期間鎖定首頁錄影操作。
- MP4 輸出可指定位置與檔名，不覆寫已有同名檔案。
- 新增較低調的專案錄影總時間，與本次錄影時間使用同一次狀態取樣；暫停時可修改停止後自動輸出 MP4 的選項。
- 修正 MKV 封包缺少 duration 時被忽略的問題：依有效 PTS 與最後觀測影格間距判讀時間，避免短片段無法保存及停止時出現 Missing video timing or geometry。缺乏足夠時間資訊或無效素材仍拒絕，不刪除原始素材。

### 相容性與限制

- 合併片段使用專案 schema 3，舊版無法開啟。升級前請備份專案；原始 MKV 保留。
- 舊專案先前已保存的少算時間不會自動改寫。本次不包含素材插入、圖層疊加及預覽直接變形操作。
- 已完成重點自動測試，包括自製素材反覆暫停／續錄後輸出 MP4；不等於 Windows 原生實機、長時間音畫同步、實際磁碟耗盡或全部 Release Gate 驗收。
- 安裝包未具可信發行者簽章，macOS 未公證；Windows FFmpeg 完整對應原始碼核對仍待完成。不宣稱所有安全、授權或硬體問題已解決。

## English

- Use OpenCam consistently as the Windows installer and installed application name.
- Add a fullscreen-only preview seek bar.
- Merge adjacent clips with undo support. Clip-list context menus provide rename, merge, group, ungroup and delete actions; grouped rows share a continuous frame without merged-count suffixes.
- Selecting a clip seeks to its beginning. Both return and close paths handle unsaved edits, and recording controls on the home window are locked while the editor is open.
- Choose the MP4 destination and filename without overwriting existing files.
- Show project recording duration alongside the current session, sampled in the same status response. Allow changing automatic MP4 export while paused.
- Handle valid MKV packet PTS even when packet duration is missing, inferring the final interval from observed presentation timestamps. This fixes skipped footage and short-segment save failures. Insufficient timing or invalid media still fails safely; original media is retained.

### Compatibility and limitations

- Merged clips require project schema 3 and cannot be opened by older versions. Back up projects before upgrading.
- Previously saved, underestimated timings are not rewritten automatically. Media insertion, overlays and direct preview transforms are not included.
- Focused automated tests include repeated pause/resume and actual MP4 export with synthetic media. Native Windows, long-duration A/V sync, physical disk-exhaustion and complete Release Gate acceptance remain pending.
- Packages lack trusted publisher signing and macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. This release does not claim all security, licensing or hardware issues are resolved.
