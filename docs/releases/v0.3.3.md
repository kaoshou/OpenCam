# OpenCam v0.3.3

## 繁體中文

- 主畫面與編輯器新增「輸出… → 網頁播放器」。
- 匯出為包含 index.html、media.mp4 與 opencam-player.js 的獨立資料夾，可離線播放或上傳網站。
- 章節依剪輯後的片段名稱、順序與時間產生，合併片段顯示為一個章節。
- 播放器提供進度、音量、倍速、寬螢幕與全螢幕控制，章節清單可捲動。
- 時間軸拖曳改為只調整排序，裁剪使用明確的修剪、分割或刪除範圍操作。

## English

- Added Export… → Web player on the home screen and in the editor.
- Export a standalone folder containing index.html, media.mp4 and opencam-player.js for offline playback or website hosting.
- Chapters follow edited clip names, order and timing, with compound clips shown as one chapter.
- The player includes seeking, volume, speed, wide-screen and fullscreen controls, plus a scrollable chapter list.
- Timeline dragging now reorders clips; trimming uses explicit trim, split or range-deletion actions.
