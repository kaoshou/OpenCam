# OpenCam v0.3.3 — 網頁播放器輸出與介面改善 / Web player export and editor polish

## 繁體中文

- 主畫面與編輯器的「輸出…」提供 MP4 影片及網頁播放器；既有自動輸出 MP4 行為保留。
- 網頁輸出建立獨立資料夾，固定含 index.html、media.mp4、opencam-player.js。HTML／JS 註明由 OpenCam 輸出及專案網址；資料格式 opencam.web-player/schemaVersion 1 可供 Video-to-Subtitle 辨識，解析時不用 eval。
- 章節依保存後的片段順序、名稱及時間產生；合併片段是一個章節。索引顯示起始時間與片段長度，超出高度時在清單內捲動。
- 網頁採 OpenCam 藍灰配色、輕巧標題區及影片內控制列：進度、播放／暫停、靜音／音量、速度、寬螢幕及全螢幕。全螢幕仍可操作進度；不支援原生全螢幕時提供頁面內滿版，Esc 可退出。
- 網頁不需要 CDN、外部字型、網路 API 或 EverCam 轉換；將三個檔案一起搬移即可，瀏覽器需支援 H.264／AAC。
- 網頁輸出沿用驗證過的 MP4 輸出管線，入口頁最後發布；取消不覆寫既有成品或原始 MKV，可能留下空資料夾。
- 時間軸拖曳僅排序，不再以邊緣拖曳裁剪。明確的分割、刪除範圍及復原保留；屬性區操作按鈕統一尺寸、圖示與排列。

### 相容性與未完成驗收

- 專案與網頁資料格式沒有額外升版。既有 schema 3 合併專案仍不能由舊版開啟；請備份整個專案。先前誤裁或少算的已保存時間不會自動修復。
- 瀏覽器實際離線播放、排版、全螢幕及觸控仍待人工驗收；自動互動測試不代表真實瀏覽器已驗收。
- Windows 原生錄影／編輯影音／輸出、長時間音畫同步、macOS 視覺驗收、實際磁碟耗盡與完整實體 Release Gate 未全部完成。
- 先前 Windows 心跳重試與快速輸出偶發回退仍不能宣稱根治；macOS 已重現的 4K IPC 兩秒截斷已修補，但不能保證所有高負載情境。
- 安裝包無可信發行者簽章，macOS 未公證；Windows FFmpeg 完整對應原始碼核對仍待完成。發布不代表所有可靠性、安全或授權問題皆已解決。

## English

- Both export menus offer MP4 video and Web player. Existing automatic MP4 export remains unchanged.
- Create a unique folder with index.html, media.mp4 and opencam-player.js. HTML/JS identify OpenCam and its repository. The opencam.web-player/schemaVersion 1 data can be identified and parsed by Video-to-Subtitle without evaluating JavaScript.
- Chapters follow the saved logical clip names, order and timings; merged clips form one chapter. The bounded, scrollable index displays start times and chapter durations.
- Use OpenCam's blue/gray theme, a compact title header and overlay controls for seeking, play/pause, mute/volume, speed, wide-screen and fullscreen. Fullscreen retains the controls; unsupported native fullscreen falls back to an in-page view with Escape to exit.
- No CDN, external fonts, network API or EverCam conversion is required. Move all three files together and use an H.264/AAC-capable browser.
- Package the existing verified MP4 export and publish the entry page last. Cancellation preserves existing outputs and original MKVs, though an empty folder may remain.
- Timeline dragging only reorders and no longer trims clip edges. Explicit split, range deletion and undo remain available. Inspector buttons use consistent icons, sizes and layout.

### Compatibility and pending acceptance

- No additional project or web-data schema upgrade. Existing merged schema 3 projects still require compatible versions. Back up complete projects; previously saved accidental trims or underestimated durations are not rewritten automatically.
- Real-browser offline playback, layout, fullscreen and touch acceptance remain pending; automated interaction tests do not establish browser acceptance.
- Native Windows recording/editor audiovisual/export, long-duration A/V sync, macOS visual acceptance, physical disk-exhaustion and the complete physical Release Gate are not fully verified.
- Earlier intermittent Windows heartbeat retry and fast-export fallback issues are not claimed fully resolved. The reproduced macOS 4K IPC two-second truncation was fixed, not every high-load scenario.
- Packages lack trusted publisher signing and macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication does not imply all reliability, security or licensing issues are resolved.
