# OpenCam v0.3.4

## 繁體中文

- 新增 SRT／VTT 多語字幕匯入，可選取或拖放檔案，並設定預設字幕語言。
- 一般與全螢幕預覽可切換字幕語言、關閉字幕，以及調整大小、配色、背景透明度與位置。
- 網頁播放器新增多語 CC 選單及逐字稿搜尋，支援關鍵字標示、點擊跳轉與跟隨播放。
- 剪輯時序變更後，網頁輸出可選擇附加字幕、不附加或取消；字幕時間不會自動改寫。
- 保存字幕使用專案格式 4，v0.3.3 及以前無法開啟。字幕不燒入 MP4，請保留完整專案備份。

## English

- Added SRT/VTT subtitle import by selection or drag-and-drop, with multiple languages and a default track.
- Regular/fullscreen preview supports language/off, size, color, background opacity and position controls.
- Web player exports gain multilingual CC and transcript search, with highlighting, click-to-seek and follow playback.
- After timeline edits, Web export lets you include captions, omit them or cancel; subtitle timing is not changed automatically.
- Saved captions use project format 4, incompatible with v0.3.3 and earlier. Captions are not burned into MP4; keep complete project backups.
