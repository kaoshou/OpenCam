# OpenCam v0.3.4 — 多語字幕與逐字稿搜尋 / Multilingual captions and transcript search

## 繁體中文

- 編輯器新增「附加影片字幕」，選取或拖放 SRT／VTT，多語檔案以唯一名稱保存到專案內，同名不覆蓋。語言名稱依中英文介面顯示並附代碼，清單卡片單選預設字幕。
- 字幕套用進編輯狀態／復原草稿，儲存專案才持久保存；替換與移除保留歷史資產供復原。取消匯入可能留下未引用資產，不冒險刪除復原需要的資料。
- 一般／全螢幕預覽選擇語言或關閉字幕，大小、配色、背景透明度及位置即時調整；不改專案預設語言，不燒入 MP4。
- 網頁維持 index.html、media.mp4、opencam-player.js 三檔案，加入預設開啟的多語 CC 控制與純文字字幕。語系選單只顯示名稱及代碼，不帶檔名。
- 右側「章節／逐字稿」分頁，搜尋字幕、關鍵字標示、點擊跳轉、可選跟隨播放。點擊逐字稿保持原本播放／暫停狀態；搜尋時暫停自動跟隨，固定高度內捲動、分批顯示大量字幕。
- 裁剪、重排或續錄改變最終時間軸時，需確認字幕同步；網頁輸出可附加、不附加或取消，不自動改寫字幕時間。
- 命名視窗按鈕置中、輸出箭頭縮小置中、字幕卡片美化與語言完整顯示；網頁章節列緊湊，編號框與內容高度對齊，標題摘要不再重複 OpenCam。
- README、GitHub Pages 與中英文說明更新，重新產生首頁／設定／編輯器／字幕視窗介面展示，使用自製教學影片與字幕，並非實機驗收證據。無新增應用第三方依賴。

### 相容性與限制

- **保存附加字幕使用專案格式4，v0.3.3及以前不能開啟，請先備份整個專案。** 無字幕專案不因此自動升版。網頁資料格式仍為 opencam.web-player/schemaVersion1，可選字幕資料位於同一 JS 內。
- 支援 UTF-8及含 BOM 的 UTF-16；最多32軌，每檔10 MiB／100,000則字幕／每則10,000字，網頁解析字幕合計64 MiB上限。純文字呈現，不執行字幕 HTML／樣式指令。匯入內容／來源校驗失敗會拒絕使用。
- MP4不燒錄字幕；原生畫中畫字幕不在支援範圍。本機瀏覽器保存偏好受儲存政策限制，不保證搬移資料夾／跨瀏覽器後保留。
- 真實瀏覽器離線／觸控／全螢幕、Windows原生錄影／編輯影音／輸出、長時間A/V、macOS視覺、實際磁碟耗盡及完整實體Release Gate未全部完成。Windows心跳重試／快速輸出偶發回退不能宣稱根治。
- 安裝包無可信發行者簽章，macOS未公證；Windows FFmpeg完整對應原始碼核對仍待完成。依使用者授權發布，不表示全部可靠性、安全、授權或實機驗收通過。

## English

- Attach SRT/VTT by selection or drop. Unique project-owned copies preserve same-name multilingual assets. Localized language labels include codes; choose the default on a subtitle card.
- Apply edits drafts; explicit Save persists. Replacement/removal retains assets for undo/recovery; canceled import may leave an unreferenced asset.
- Preview/fullscreen language/off, size, theme, opacity and position controls are view-only. MP4 has no caption burn-in.
- Three-file Web packages add default-on multilingual CC controls and safe plain-text cues. Language menus omit filenames.
- Chapter/transcript tabs offer full-text search, highlighting, seek preserving play/pause, optional following and bounded scrolling with batched rows. Searching suspends automatic following.
- Timeline changes require subtitle-sync confirmation, omission or cancellation before Web export; cues are not retimed automatically.
- Center naming-dialog actions, shrink/center export chevrons, improve subtitle cards and compact chapter badges. Refresh bilingual README, Pages and genuine UI renders using original authored tutorial media; no new application dependencies.

### Compatibility and limits

- **Saved subtitles require project format4; v0.3.3 and earlier cannot open them. Back up complete projects first.** Projects without captions retain their schema. Web format remains opencam.web-player/schemaVersion1 with optional caption data in the existing JS.
- UTF-8/BOM-marked UTF-16;32 tracks maximum,10 MiB/100,000 cues/10,000 characters per cue;64 MiB aggregate parsed Web cues. Render plain text, not executable HTML/styles. Changed/invalid imported assets fail verification.
- No MP4 burn-in or native PiP captions. Browser storage policies may prevent persistent preferences or carrying them across folder moves/browsers.
- Real-browser offline/touch/fullscreen, native Windows recording/editor A/V/export, long A/V sync, macOS visuals, physical disk exhaustion and the full physical Release Gate remain incomplete. Intermittent Windows heartbeat/fast-export fallback issues are not claimed resolved.
- No trusted publisher signing/macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized and does not establish all reliability, security, licensing or device acceptance.
