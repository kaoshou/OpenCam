# OpenCam v0.3.5

## 繁體中文

- 拖曳時間尺與全螢幕進度條時持續更新預覽，放開後定位至選定位置。
- 播放中拖曳會先暫停，放開後續播。
- 整理預覽控制列，字幕語言與外觀收進同一選單，窄視窗可換行。
- 起點立即顯示固定標記，設定有效終點後顯示選取範圍；重設起點會清除舊終點。標記本身不裁剪影片。

## English

- Preview updates while dragging the timeline/fullscreen seek bar and settles at the selected position on release.
- Scrubbing during playback pauses first and resumes on release.
- Refined compact preview controls, with caption language/appearance in one menu and wrapping in narrow windows.
- Mark in immediately shows a fixed flag; a valid mark out highlights the range. A new start clears the old end. Marking does not trim media.
