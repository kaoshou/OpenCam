# OpenCam v0.3.5 — 拖曳預覽與範圍標記 / Progressive scrubbing and range markers

## 繁體中文

- 拖曳時間尺及全螢幕進度條時保留預覽，持續顯示途中完成的影格；同時僅一個解碼請求。放開後定位最後位置，過期專案／修訂／畫質影格不可覆蓋。
- 播放中拖曳先暫停一次，放開後從選定位置續播；明確停止取消自動續播。延遲停止回覆不會把播放頭拉回舊位置。
- 預覽控制列縮減高度、美化排列；播放與時間放一起，畫質、縮放、聲音、全螢幕及字幕選單緊湊排列，窄視窗換行。字幕語言与外觀收在同一選單，無警告時不留空白列。
- 起點立即顯示固定綠色「起」旗標／垂直線；有效終點顯示橘色「終」旗標與覆蓋影片、音軌的半透明選取區。重設起點清除舊終點；未設起點或終點不晚於起點時提示並禁止刪除範圍。標記本身不裁剪影片。
- 更新中英文 README、使用說明、網站與程式展示；使用自製素材，並非實機驗收證據。沒有新第三方依賴、專案格式或錄影／輸出流程變更。

### 相容性與限制

- 延續格式4字幕專案：v0.3.3及以前不能開啟，請備份完整專案。MP4不燒入字幕，字幕不自動對時。
- 刷新速度依素材、磁碟、CPU及畫質而定，不保證30／60 FPS拖曳；Windows／macOS真實高解析度與全螢幕視覺仍需實機確認。
- Windows原生錄影、長時間A/V、macOS視覺、實際磁碟耗盡、瀏覽器離線／觸控／全螢幕及完整實體Release Gate未全部完成。Windows心跳／快速輸出偶發問題不宣稱根治。
- 未具可信發行者簽章／macOS公證；Windows FFmpeg完整對應原始碼核對仍待完成。依使用者授權發布，不表示全部可靠性、安全、授權或實機驗收通過。

## English

- Keep the preview visible and publish completed frames while dragging the timeline/fullscreen seek bar, with one in-flight decode. Release settles at the final position; obsolete project/revision/quality frames cannot replace it.
- Playing preview pauses once during scrubbing and resumes at release. Explicit Stop cancels resumption; delayed stop acknowledgments cannot rewind the playhead.
- Compact wrapping controls keep play/time together. Caption language and appearance share a menu, with no empty warning row.
- Mark in immediately shows a fixed teal IN flag/line. Valid mark out shows an orange OUT flag and highlights video/audio lanes. A new start clears the old end; missing/equal/reversed endpoints show guidance and cannot delete a range. Marking never trims media.
- Refresh bilingual README, guides, website and genuine UI renders using authored demo media, not device-acceptance evidence. No new dependency, schema or recording/export flow changes.

### Compatibility and limits

- Subtitle projects retain format4; v0.3.3 and earlier cannot open them. Back up complete projects. No MP4 caption burn-in or automatic retiming.
- Refresh depends on media, storage, CPU and quality; no30/60 FPS scrubbing guarantee. Native high-resolution/fullscreen visual acceptance remains pending.
- Native Windows capture, long A/V, macOS visuals, physical disk exhaustion, browser offline/touch/fullscreen and the complete physical Release Gate remain incomplete. Intermittent Windows heartbeat/fast-export issues are not claimed resolved.
- No trusted signing/macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized, not complete reliability, security, licensing or device acceptance.
