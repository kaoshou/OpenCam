# OpenCam v0.3.6

## 繁體中文

- 改善未剪輯 H.264 錄影的 MP4 快速輸出，支援更多缺少影格長度資訊的 MKV。
- 相容完整片段可直接封裝或串接，必要時只轉換音訊。
- 輸出狀態明確區分直接封裝、處理音訊、重新編碼與檢查 MP4。
- 裁剪、效果或不相容素材仍使用重新轉檔，保留原始素材。

## English

- Improved fast MP4 export for unedited H.264 recordings, including more MKVs with missing frame-duration information.
- Compatible complete segments can be packaged or joined while converting only audio when needed.
- Clear status labels distinguish packaging, audio processing, re-encoding and MP4 checking.
- Trims, effects and incompatible media continue to use rendering, preserving original recordings.
