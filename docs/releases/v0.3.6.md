# OpenCam v0.3.6 — 快速輸出改善 / Fast export improvements

## 繁體中文

- 改善未剪輯 H.264 錄影的 MP4 快速輸出。部分 MKV 缺少封包影格長度時，使用下一個嚴格遞增的顯示時間戳推導間隔；末幀須有前一個間隔，且符合幀率及時間基底的量化誤差，才允許保留影片封裝。
- 單一完整片段可直接封裝；多個相容完整片段可保留原影片串接，必要時只重新處理音訊。不是所有未剪輯素材都能快速輸出；素材雜湊檢查、封裝與輸出校驗仍需時間。
- 時間戳重複／倒序、尾端不明確、缺少音訊封包長度、格式不相容、裁剪或效果仍回退到原有安全重新編碼。原始素材、輸出校驗與取消保護維持不變。
- 中英文輸出狀態整理為直接封裝 MP4、處理音訊（不重編影片）、重新編碼影片與校驗 MP4。更新 README 及網站說明；未增加第三方依賴或變更專案格式。

### 相容性與限制

- 延續格式4字幕專案；v0.3.3及以前不能開啟，請備份完整專案。MP4不燒入字幕，字幕不自動對時。
- 未重新測量所有設備的輸出速度，不承諾固定加速倍率。Windows 原生錄影、長時間 A/V、macOS 視覺、實際磁碟耗盡、瀏覽器離線／觸控／全螢幕及完整實體 Release Gate 仍未全部完成。
- Windows 心跳與快速輸出偶發問題不宣稱全部根治。未具可信發行者簽章／macOS 公證；Windows FFmpeg 完整對應原始碼核對仍待完成。依使用者授權發布，不表示全部可靠性、安全、授權或實機驗收通過。

## English

- Improve MP4 fast export for unedited H.264 recordings. When MKV video packet durations are missing, derive intervals from strictly increasing presentation timestamps. The final frame requires a preceding interval corroborated by frame rate and time-base quantization before stream copy is permitted.
- A compatible whole segment can be packaged directly. Multiple compatible whole segments can preserve encoded video while joining, processing only audio when necessary. Not every unedited recording qualifies; source hashing, packaging and output verification still take time.
- Duplicate/reordered timestamps, ambiguous tails, missing audio packet durations, incompatible formats, trims and effects retain verified-render fallback. Original media, output verification and cancellation protections remain unchanged.
- Clarify bilingual status labels for MP4 packaging, audio processing without video re-encoding, video re-encoding and MP4 verification. Update README and website descriptions without new dependencies or project-format changes.

### Compatibility and limits

- Subtitle projects retain format4; v0.3.3 and earlier cannot open them. Back up complete projects. No MP4 caption burn-in or automatic retiming.
- No fixed speedup is promised or measured across all devices. Native Windows capture, long A/V, macOS visuals, physical disk exhaustion, browser offline/touch/fullscreen and the complete physical Release Gate remain incomplete.
- Intermittent Windows heartbeat and fast-export issues are not claimed fully resolved. No trusted signing/macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized, not complete reliability, security, licensing or device acceptance.
