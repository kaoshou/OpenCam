# OpenCam v0.3.7

## 繁體中文

- 新增錄前確認：核對錄製範圍、系統聲音與麥克風，提供隔離試錄及回放；試錄不加入正式專案，必須完成來源確認後才正式錄製。
- 新增可設定的 0／3／5 秒錄製倒數，預設 3 秒。開始新錄製、附加或插入前使用；暫停後續錄不重複倒數。可按取消、Escape 或開始／停止快捷鍵取消，取消不建立正式錄製 session；倒數結束重新核對先前確認。
- 錄製中新增「標記重點」與可設定快捷鍵，預設 Ctrl+Shift+M。Windows 與 macOS 提供全域重點快捷鍵，設定衝突或註冊失敗會提示。macOS 開始／停止、暫停／繼續仍維持前景快捷鍵。
- 編輯器可由重點清單定位、改名、刪除；紫色旗標隨片段重排及剪輯投影。資料獨立保存在專案內 `opencam-bookmarks.json`，不改寫影片或主專案格式，不自動變成網頁章節；改名／刪除不納入片段復原／重做。
- 新增麥克風無聲提醒設定，預設開啟。僅在錄製麥克風且持續收到 30 秒無聲音量資料時提示；恢復聲音、暫停、停止、關閉設定或停用麥克風會清除並重新計時。音量資料不可用不當作無聲。
- 提醒不暫停、停止或重啟錄影，不發出提示音或搶焦點。Windows 10 2004 以上只有成功設定並讀回擷取排除狀態後才顯示半透明浮窗；失敗則使用程式內警示。macOS 目前的 AVFoundation 路徑僅顯示程式內警示，不建立無法確認排除的浮窗。
- 更新繁體中文／英文 README、使用說明與網站功能介紹。沿用已標示版本的示範圖片，不將舊圖片當作新版實機驗收證據。

### 相容性與限制

- 維持格式4字幕專案，v0.3.3及以前不能開啟，請先備份完整專案。字幕不燒入 MP4、不自動對時。請整個專案資料夾一起保留，包含重點附屬檔。
- 無聲提醒只是音量判斷，不保證辨識是否有人說話。UI／IPC 無法連續取得音量時不累計無聲。Windows 浮窗實際是否排除於各擷取模式、macOS 裝置收音、全域快捷鍵與倒數的多螢幕／DPI 行為仍需實機驗收。若 OpenCam 本身位於錄影範圍內，程式內警示仍可能被錄入。
- Windows 原生錄影、長時間 A/V、macOS 視覺、實際磁碟耗盡、瀏覽器離線／觸控／全螢幕與完整實體 Release Gate 仍未全部完成。不宣稱歷史 Windows 心跳／快速輸出偶發問題全部根治，也不保證每個未剪輯素材皆可快速輸出。
- 未具可信發行者簽章或 macOS 公證；Windows FFmpeg 完整對應原始碼核對仍待完成。依使用者授權發布，不表示全部可靠性、安全、授權或實機驗收通過。

## English

- Add preflight confirmation of capture bounds, system audio and microphone, with isolated trial recording and replay. Trials never enter the real project; source confirmation is required before starting.
- Add a configurable 0/3/5-second recording countdown, default 3, for new, appended and inserted recordings, not simple paused resume. Cancel using the button, Escape or start/stop shortcut without creating a real recording session. Recheck accepted preflight configuration after countdown.
- Add recording bookmarks using a button or configurable shortcut, default Ctrl+Shift+M. Windows and macOS support a global bookmark shortcut and report conflicts or registration failures. macOS start/stop and pause/resume remain foreground shortcuts.
- Seek, rename or delete bookmarks in the editor. Purple flags project through clip reorder and edits. Project-owned `opencam-bookmarks.json` does not rewrite media or change the main project format. Bookmarks do not automatically become web chapters; rename/delete is separate from clip undo/redo.
- Add default-on microphone silence reminders. Warn only after 30 seconds of continuously observed silence while recording the microphone. Sound, pause, stop, disabling reminders or disabling the microphone clears and resets the interval. Missing level telemetry is not silence.
- Advisories never pause, stop or restart recording, play notification sounds or activate a window. Windows 10 version 2004 or later reveals a translucent floating warning only after successful capture-exclusion setup and readback; failures use an in-app advisory. The current macOS AVFoundation path uses in-app advisories only, without creating an unverified floating warning.
- Update bilingual README, user guides and website features. Existing illustrative images retain their actual version labels and do not establish device acceptance for this version.

### Compatibility and limits

- Subtitle projects retain format4, incompatible with v0.3.3 and earlier. Back up the whole project folder, including bookmark sidecars. No MP4 caption burn-in or automatic subtitle retiming.
- Silence detection measures levels, not speech. UI/IPC observation gaps do not accumulate silence. Actual Windows warning exclusion per capture backend, macOS audio devices, background shortcuts and multi-display/DPI countdown behavior still require physical validation. In-app advisories can be captured if OpenCam itself is inside the recording region.
- Native Windows capture, long A/V, macOS visuals, physical disk exhaustion, browser offline/touch/fullscreen and the complete physical Release Gate remain incomplete. Historical intermittent Windows heartbeat/fast-export issues are not claimed fully resolved; not every unedited source qualifies for fast export.
- No trusted publisher signing or macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized, not complete reliability, security, licensing or device acceptance.
