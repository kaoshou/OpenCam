# OpenCam v0.3.7

## 繁體中文

- 新增錄前範圍與音源確認，提供獨立試錄與回放。
- 新增 0／3／5 秒錄製倒數，可取消；預設為 3 秒。
- 錄影中新增「標記重點」及自訂快捷鍵，預設 Ctrl+Shift+M；編輯器可定位、改名及刪除重點。
- 新增麥克風連續無聲 30 秒提醒，不暫停或停止錄影；Windows 提供符合擷取排除條件的浮窗，macOS 使用程式內提示。
- 重點資料隨專案保存，不修改影片，也不會自動轉為網頁章節。

## English

- Added preflight checks for the capture area and audio inputs, with an isolated trial and replay.
- Added a cancellable 0/3/5-second countdown, defaulting to 3 seconds.
- Added recording bookmarks and a configurable shortcut, default Ctrl+Shift+M, with seek, rename and delete in the editor.
- Added a reminder after 30 seconds of microphone silence without pausing/stopping recording. Windows supports an excluded floating advisory when available; macOS uses an in-app message.
- Bookmarks are saved with the project without rewriting video or automatically becoming Web chapters.
