# OpenCam v0.3.8

## 繁體中文

- 修正錄前檢查在引擎初始化／主動停止時，被輪詢誤判成擷取失敗並持續黑畫面的問題；補上有界錯誤診斷。
- 錄前預覽載入、試錄準備／錄製、試錄完成及失敗時提供明確提示。縮減視窗高度、整理音量卡與按鈕；直接按「確認並開始錄製」，不需額外勾選。裝置錯誤或尚未就緒仍會阻擋開始。
- 移除無法準確銜接實際錄影開始時刻的倒數及其設定。確認後直接準備錄製，請等主畫面顯示「錄製中」才開始講解；舊倒數設定不再生效。
- 錄前檢查以主畫面選擇的音訊來源為準；未勾選的來源明確顯示本次不會錄製，隱藏音量條與收音引導。
- 五秒試錄期間，已勾選的麥克風／系統音訊顯示試錄引擎的即時音量，不沿用錄前舊讀值。缺少或過期音量資料不當作正常收音；完成與回放時停止即時監測，請播放確認實際聲音。
- 編輯器重點清單可在播放頭位置新增重點，整理新增、定位、改名及刪除介面；資料仍保存在專案內 `opencam-bookmarks.json`，不改寫原始影片。
- 網站示範圖片改用頁內 lightbox，可關閉、以 Escape 返回並保留鍵盤焦點，不再直接開啟圖片頁。
- 同步繁體中文／英文 README、指南與網站說明。示範圖保留實際版本標示，沒有將舊圖當作新版實機驗收。

### 相容性與限制

- 字幕專案延續格式4，v0.3.3及以前不能開啟；請備份並保留完整專案資料夾及重點附屬檔。字幕不燒入 MP4、不自動對時；重點不自動轉為網頁章節。
- 錄前預覽仍經過編碼／解碼，可能有延遲，專用低延遲預覽尚未實作。音量顯示不保證聲音內容或後續整段錄音正常，請試錄回放確認；啟動準備也不保證立即完成。
- 使用者已回報 Windows 新測試版可看到錄前畫面；這不是所有裝置、編碼器或音源組合的完整驗收。Windows 原生及長時間 A/V、macOS 視覺、實際磁碟耗盡、瀏覽器離線／觸控／全螢幕及完整實體 Release Gate 仍未全部完成。
- Windows 無聲提醒浮窗的實際擷取排除、原生收音、背景快捷鍵與多螢幕 DPI 仍需實機確認；程式內提示位於錄影範圍時可能被錄入。歷史 Windows 心跳／快速輸出偶發問題不宣稱全部根治。
- 套件未具可信發行者簽章或 macOS 公證；Windows FFmpeg 完整對應原始碼核對仍待完成。依使用者授權發布，不代表全部可靠性、安全、授權或實機驗收已通過。

## English

- Fix preflight polling incorrectly treating encoder initialization or intentional shutdown as a persistent capture failure, which could leave a black preview. Add bounded failure diagnostics.
- Show clear loading, trial preparation/recording, ready and failure feedback. Make the window more compact and refine audio cards and buttons. Use one confirmation button without extra checkboxes; unavailable devices or incomplete preparation still block starting.
- Remove the countdown and its setting because it did not accurately indicate when capture began. Confirmation now starts recording preparation directly; wait for the main window to show Recording. Old countdown preferences are ignored.
- Respect the main window's audio selections in preflight. Unselected inputs explicitly say they will not be recorded, without level bars or prompts to speak/play sound.
- During the five-second trial, selected microphone/system inputs show current levels from the trial engine rather than old preflight samples. Missing or stale samples are not reported as successful capture. Live monitoring stops for completed trials and replay; play the trial to verify actual sound.
- Add bookmarks at the editor playhead from the bookmark list and refine add, seek, rename and delete controls. Bookmarks remain in project-owned `opencam-bookmarks.json` without rewriting source media.
- Open website screenshots in an inline lightbox with close, Escape and keyboard-focus handling instead of navigating to an image page.
- Update bilingual README, guides and website descriptions. Illustrations retain their actual version labels and do not establish device acceptance for this release.

### Compatibility and limits

- Subtitle projects retain format4, incompatible with v0.3.3 and earlier. Back up the complete project folder and bookmark sidecars. No MP4 subtitle burn-in or automatic retiming; bookmarks do not automatically become web chapters.
- Preflight preview still uses encoding/decoding and may lag; a dedicated low-latency path is not implemented. Meters do not guarantee audio content or continued capture throughout a recording. Verify sound by replaying a trial; startup preparation can still take time.
- A user confirmed that the new Windows test build displays the preflight preview. This is not complete acceptance across devices, encoders and audio combinations. Native Windows capture and long A/V, macOS visuals, physical disk exhaustion, browser offline/touch/fullscreen and the complete physical Release Gate remain incomplete.
- Actual Windows advisory capture exclusion, native audio, background shortcuts and multi-display DPI still require device testing. In-app advisories can be recorded when inside the capture region. Historical intermittent Windows heartbeat/fast-export issues are not claimed fully resolved.
- No trusted publisher signing or macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized, not complete reliability, security, licensing or device acceptance.
