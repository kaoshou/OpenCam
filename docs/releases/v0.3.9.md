# OpenCam v0.3.9

## 繁體中文

- 新增「錄製前檢查」設定，預設開啟；關閉後可直接進入錄製準備。
- 降低錄前預覽的緩衝，改善畫面更新的反應。
- 滑鼠移到時間軸紫色重點旗標時顯示完整名稱，點擊可跳轉。
- 修正錄前啟動失敗時，狀態輪詢與清理同時進行造成的錯誤判斷。

## English

- Added a default-on Recording preflight setting; disabling it goes directly to recording preparation.
- Reduced preflight preview buffering to improve responsiveness.
- Hovering a purple timeline bookmark shows its full name; clicking seeks to it.
- Fixed incorrect status handling when polling overlaps cleanup after a preflight startup failure.
