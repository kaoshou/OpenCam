# OpenCam v0.3.9

## 繁體中文

- 新增錄製前檢查設定，預設開啟；關閉後開始／繼續錄影不顯示檢查視窗，但保留權限、專案、輸出及真正啟動確認。
- 即時錄前預覽使用專用低緩衝輸出：CPU H.264 加入零延遲設定，MKV cluster 由 1000ms 改為 100ms。硬體編碼器保留原選擇；正式錄影與五秒試錄參數不變，不靠輸出串流存在與否判斷預覽。
- 滑鼠停留在時間軸紫色重點旗標上顯示完整名稱，移開／點擊時隱藏，保留點擊跳轉功能。
- CI 保存有界工具版本、允許清單內的 runner 資訊及 TRX 測試結果；更新分層測試計畫，不降低測試斷言、音訊驗證或安全發布門檻，也不以重跑到綠色取代診斷。
- 同步中英文 README、使用指南與網站說明。既有示範圖保留真實版本標示，未新增私人桌面截圖。

### 相容性與限制

- 無新增應用程式套件或專案格式；字幕仍使用格式4，v0.3.3及以前不能開啟。請備份完整專案及重點附屬檔；字幕不燒入 MP4、不自動對時，重點不自動轉為網頁章節。
- 關閉錄前檢查代表不再透過試錄確認畫面與聲音，請自行確認裝置。預覽更新頻率未提高，實際延遲依設備、素材及編碼器而定，不保證 30／60FPS、特定毫秒延遲或立即開始錄製。
- 本機合成與 headless 測試不等於 Windows 原生／GPU 音訊組合、長時間 A/V、macOS 視覺、實際磁碟耗盡、瀏覽器離線／觸控／全螢幕、浮窗擷取排除、背景快捷鍵及多螢幕 DPI 實機驗收。完整實體 Release Gate 尚未全部完成，歷史 Windows 心跳／快速輸出偶發問題不宣稱全部根治。
- 套件未具可信發行者簽章或 macOS 公證；Windows FFmpeg 完整對應原始碼核對仍待完成。依使用者授權發布，不代表全部可靠性、安全、授權或實機驗收已通過。

## English

- Add a default-on recording-preflight preference. Disabling it skips the check window when starting/resuming, while retaining permission, project, output and actual-start acknowledgement checks.
- Use a dedicated lower-buffering live preview profile: CPU H.264 gets zero-latency options and MKV clusters change from 1000ms to 100ms. Hardware encoder selection is retained; saved recordings and five-second trial settings are unchanged. A bound output stream alone does not enable preview mode.
- Hover over purple timeline bookmark flags to display full names. Moving away or clicking hides the tooltip; click-to-seek remains unchanged.
- Preserve bounded tool-version/allowlisted runner metadata and TRX evidence in CI. Update the layered testing plan without weakening assertions, audio validation or release gates, or substituting reruns-until-green for diagnosis.
- Update bilingual README, guides and website descriptions. Existing illustrations retain their actual version labels; no private desktop screenshots are added.

### Compatibility and limits

- No new application packages or project format. Subtitle projects retain format4, incompatible with v0.3.3 and earlier. Back up the complete project and bookmark sidecars. No MP4 subtitle burn-in, automatic retiming or automatic bookmark-to-web-chapter conversion.
- Disabling preflight removes the trial-based picture/sound check; verify devices yourself. Preview update frequency is unchanged. Latency depends on hardware, media and encoder; no guaranteed 30/60FPS, millisecond target or immediate recording startup.
- Local synthetic/headless tests do not establish native Windows/GPU/audio combinations, long A/V, macOS visuals, physical disk exhaustion, browser offline/touch/fullscreen, advisory capture exclusion, background shortcuts or multi-display DPI acceptance. The complete physical Release Gate remains incomplete. Historical intermittent Windows heartbeat/fast-export issues are not claimed fully resolved.
- No trusted publisher signing or macOS notarization. Complete corresponding-source verification for Windows FFmpeg remains pending. Publication is user-authorized, not complete reliability, security, licensing or device acceptance.
