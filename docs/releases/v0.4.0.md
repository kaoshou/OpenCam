# OpenCam v0.4.0

## 繁體中文

### 匯出與編輯

- MP4 新增「保留目前設定」「標準壓縮」「較小檔案」品質選項，以及原始／最高 1080p／最高 720p 解析度。
- 整部影片、單一片段及網頁播放器內的 MP4 共用設定流程，先選品質、再選儲存位置，並記住上次選擇。保持比例、不放大，不修改原始素材；壓縮會重新編碼，檔案大小依內容而異。
- 時間軸影片與音訊片段右鍵可更改名稱、刪除片段，並展開「匯出片段… → MP4／GIF」。刪除片段可復原，不刪除原始素材。

### 錄影與聲音

- 錄製前聲音確認改為三種模式：關閉、僅開始錄影時（預設）、開始錄影及暫停恢復時。
- 聲音試錄是選用功能，不要求先完成試錄才能開始正式錄影；修正試錄回放後重新檢查的收音生命週期。
- 首次錄影前即可設定「停止錄影後自動輸出 MP4」。自動輸出仍使用原設定，不套用手動匯出的品質選擇。
- 幀率提供 5／10／20／30／40 FPS，預設 10；取消 60 FPS 選項。
- 新增細長教鞭游標樣式。

### 擷取與語言

- 新增高效能擷取選項：Windows 使用 Windows Graphics Capture，Mac 使用 ScreenCaptureKit，並說明其與一般擷取的差異。Mac 請搭配自動或 Apple 硬體編碼。
- 顯示實際擷取方式，增加錄影效能紀錄；調整 WGC 搭配 NVENC 的啟動與低延遲設定。
- 新增日本語程式介面，並同步繁體中文及英文的設定與匯出說明。

保留整個專案資料夾可繼續剪輯與追加錄製，包括 MKV 素材、字幕與重點標記。字幕專案使用格式 4，v0.3.3 及以前無法開啟；字幕不燒入 MP4／GIF，也不會自動對時。網頁播放器請整個輸出資料夾一起搬移。

## English

### Export and editing

- MP4 adds Keep current settings, Standard compression and Smaller file quality options, plus original/up to 1080p/up to 720p resolution.
- Whole videos, individual clips and Web player MP4 files share the quality-before-destination workflow and remember the last choice. Aspect ratio is preserved without upscaling or modifying originals. Compression re-encodes; size depends on content.
- Right-click timeline video/audio clips to rename, delete or expand Export clip… → MP4/GIF. Clip deletion can be undone and does not delete original media.

### Recording and audio

- Audio confirmation offers Off, At recording start only (default), or At recording start and resume.
- Audio trials are optional and do not block formal recording. Fixed the audio lifecycle when rechecking after trial replay.
- Automatic MP4 export on stop can be set before the first recording. It retains its existing settings rather than the remembered manual export profile.
- Frame-rate choices are 5/10/20/30/40 FPS, default 10. The 60 FPS option is removed.
- Added a slim presentation-stick cursor style.

### Capture and language

- Optional high-performance capture uses Windows Graphics Capture on Windows and ScreenCaptureKit on Mac, with explanations of how it differs from standard capture. On Mac, use Auto or Apple hardware encoding.
- Actual capture-method display and recording performance logs; adjusted WGC/NVENC startup and low-latency settings.
- Added Japanese application UI and updated Traditional Chinese/English settings and export descriptions.

Retain the entire project folder, including original MKVs, captions and bookmarks, for editing and continued recording. Subtitle projects use format4, which v0.3.3 and earlier cannot open. Captions are not burned into MP4/GIF or automatically retimed. Move the entire Web player output folder together.
