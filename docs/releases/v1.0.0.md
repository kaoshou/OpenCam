# OpenCam v1.0.0

## 下載與開始使用

一般使用者只需選擇自己的平台，不需要另外下載原始碼或安裝編碼器。

- [Windows 安裝版](https://github.com/kaoshou/OpenCam/releases/download/v1.0.0/OpenCam_v1.0.0_Windows_x64_Setup.exe)：一般使用者建議選此項，安裝完成後開啟 OpenCam。
- [Windows 免安裝版](https://github.com/kaoshou/OpenCam/releases/download/v1.0.0/OpenCam_v1.0.0_Windows_x64_Portable.zip)：完整解壓縮後執行 `OpenCam.exe`，請保留同資料夾的其他檔案。
- [macOS 版](https://github.com/kaoshou/OpenCam/releases/download/v1.0.0/OpenCam_v1.0.0_macOS_arm64.dmg)：適用 macOS 13 以上 Apple Silicon，打開 DMG 後將 OpenCam 拖入「應用程式」。

`*-SOURCES.tar.gz`、`SOURCE-*.json/txt` 是開發者與授權查閱資料，不是安裝檔；一般使用者可略過。

## 重大更新：OBS 錄影核心

- Windows 與 macOS 正式錄影改用 OBS／libobs，改善舊流程實際 FPS 偏低、卡頓與影音同步問題；不使用 GDI／FFmpeg 錄影備援。FFmpeg 保留於聲音檢查、預覽、剪輯與匯出。
- 改善系統音訊靜音時的啟動、聲音停止／恢復的監測，以及啟動失敗後的重試與既有片段保全。
- 首次啟動預設 20 FPS；升級保留既有偏好。實際效能依硬體、解析度與負載而異。

## 數位教學與編輯

- 新增虛擬教鞭：暖白橙端、藍綠銀白、圓頭短棒、高對比黑金，提供三種大小，尖端精準定位。效果直接錄入影片，不能事後更換。
- 片段屬性修改即生效，改善輸入名稱時的畫面閃爍及焦點中斷；時間軸右鍵可改名、刪除與匯出片段。
- 修正自訂矩形設定儲存與重新開啟後的顯示器對應，開始前檢查選區有效性。
- 改善錄製中關閉保護按鈕與生命週期狀態文字。

## 分享與無障礙閱讀

- 網頁播放器支援繁體中文、英文、日文，依瀏覽器或指定預設選擇；可設定提供的語言，僅一種時隱藏選單。
- 無字幕時隱藏逐字稿頁籤；有字幕時支援搜尋、跳轉、閱讀字級／行距／背景設定及完整 HTML／TXT 下載。
- 改善鍵盤操作、Accesskey 區域定位、焦點提示、鍵盤說明及手機／平板排版。這些功能不代表教材自動取得無障礙認證。
- MP4／網頁播放器可設定匯出壓縮品質與解析度；仍保留 GIF 輸出。
- 播放器底部保留 Created with OpenCam，非英文介面另有在地語言署名。
- 更新首頁、使用手冊與 README，新增 oCam／EverCam 使用者快速指引及教鞭樣式介紹。

## 平台與授權

- Windows x64：免安裝 ZIP、安裝 EXE；macOS 13 以上 Apple Silicon：DMG。
- 套件附 OBS/libobs、FFmpeg 與其他元件的授權、對應原始碼資訊及 OpenCam 來源版本。
- Windows 必要執行階段隨附，不需另裝編碼器或尋找 DLL；大型原始碼另列下載，一般使用者不必下載。
- 目前未提供 Windows 發行者簽章或 Apple Developer ID 公證，首次開啟可能有系統安全性提示；macOS 仍需使用者授予錄製權限。請確認下載來源，不要停用系統防護。
