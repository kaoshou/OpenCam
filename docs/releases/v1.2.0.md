# OpenCam v1.2.0

## 加入影片，一起剪輯

- 編輯器新增「加入影片」，也可把影片拖入左側片段區；支援多檔依序加入、進度與取消。
- 匯入影片與錄影片段可一起排序、分割、修剪、合併、調整音量及輸出。專案保存自己的素材副本，不修改外部原檔。
- 支援常見 MP4、MOV、MKV／WebM、AVI 等容器，實際取決於編碼；目前限單一影片軌、最多一條音軌及 SDR，寬高不得超過 4096 像素。內嵌字幕與章節不自動匯入。

## 錄影前平衡聲音

- 系統音訊與麥克風各有 0–100% 音量滑桿、即時音量表，並顯示實際混音音量。
- 五秒混音試錄及回放，協助檢查兩種聲音的比例；調整後需重新試錄才能聽見新設定。
- 確認並開始錄影後記住設定；取消不儲存。不更動作業系統音量，正式錄影及暫停續錄沿用相同音量。錄影仍是一條混音音軌。

## 匯出與日常操作改善

- 相容完整片段在保留目前設定、原始解析度且僅調整音量、靜音或音訊淡入淡出時，可保留原影片編碼、只處理音訊，加快 MP4 與網頁播放器媒體輸出。修剪、影像效果與壓縮仍依需要重新編碼。
- 首次啟動預設勾選「停止錄影後自動輸出 MP4」；使用者變更後會記住，下次開啟沿用，既有專案保留自己的設定。
- 「開啟錄製專案」預設從目前設定的儲存位置開始。
- 系統匣右鍵選單依應用程式語言顯示，不再中英並列。

## English

- **Add Video:** select or drag external videos into the editor, including multiple files processed in order with progress and cancellation. Edit imported and recorded clips together. Project-owned copies preserve external originals. Common containers are supported subject to codecs; currently SDR, one video stream, at most one audio stream, and dimensions up to 4096 pixels. Embedded captions and chapters are not imported.
- **Audio balance before recording:** independent 0–100% system-audio and microphone sliders, source and actual mixed meters, and a five-second mixed trial with playback. Confirming recording remembers gains; cancelling does not. OS volume is unchanged, and recordings still contain one mixed track.
- **Faster eligible exports:** whole compatible clips with only volume, mute or audio-fade changes can retain encoded video at Keep current settings and original resolution, processing audio only for MP4 and Web-player media. Trims, visual effects and compression still render as needed.
- **Remembered automatic MP4 export:** enabled on first launch; subsequent user choices persist. Existing projects retain their own policy.
- **Project picker:** starts at the configured recording storage location.
- **Localized tray menu:** follows the selected application language without bilingual labels.
