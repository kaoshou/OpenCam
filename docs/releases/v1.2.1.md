# OpenCam v1.2.1

Windows、macOS 維持正式版本；本次新增的 **Linux 版本為 Beta**。

## Linux Beta

- 提供 Ubuntu 24.04／25.04 x64 `.deb` 安裝版及 `.tar.gz` 免安裝版。Linux 檔名均含 `Beta`，安裝後的應用程式名稱為 **OpenCam**。
- 安裝版透過 APT 處理相依套件，完成後從應用程式選單開啟，不用手動執行 `.sh`。修正 Ubuntu 25.04 無法安裝 ICU 74 的問題，使用該系統提供的 ICU 76。
- OBS／libobs 錄影核心，使用 CPU H.264 編碼；支援 X11 螢幕／區域錄影，以及 Wayland 選擇螢幕授權、暫停續錄與來源確認。沒有新增 GDI／FFmpeg 錄影備援。
- 提供專案儲存、加入影片、剪輯、預覽、MP4／GIF／網頁播放器輸出，以及系統聲音與麥克風錄前確認。
- X11 提供虛擬教鞭、螢幕註記與可設定全域快捷鍵；Wayland **尚未提供**教鞭、桌面註記及全域快捷鍵。不同 GNOME 版本、縮放、實體音訊與長時間同步仍需實機確認。

安裝指令（於下載檔所在目錄）：

```bash
sudo apt install ./OpenCam_v1.2.1_Linux_x64_Beta.deb
```

安裝後開啟 **OpenCam**。既有 Beta 套件 ID 保持 `opencam-beta`，可直接升級；移除指令為 `sudo apt remove opencam-beta`，不刪除個人錄影與專案。

## 錄影前確認

- 修正音訊初始化失敗後的狀態版本傳遞，避免介面忽略失敗結果而停留在準備中。

Linux 為 Beta，請先短錄並回放，確認畫面、音訊與輸出結果後再用於重要錄影。Windows／macOS 本次未更換錄影核心。Windows 發行者簽章與 macOS Developer ID 公證仍未提供。

## English

Windows and macOS remain the regular release. **Linux is Beta.**

- Ubuntu 24.04 / 25.04 x64 `.deb` installer and `.tar.gz` archive, with **Beta** in Linux filenames. The application menu displays **OpenCam**.
- APT handles dependencies; launch from the application menu without running a shell script. Ubuntu 25.04 uses its available ICU 76 instead of requiring ICU 74.
- OBS/libobs CPU H.264 recording on X11 and explicitly authorized Wayland screens, including pause/resume and source verification. No legacy recording fallback.
- Project recording, video import, editing, preview, audio preflight and MP4/GIF/Web-player export.
- X11 teaching pointers, screen annotations and configurable global shortcuts. These three desktop-integration features are **not yet available on Wayland**. Physical audio/video, scaling, GNOME-version compatibility and long-duration synchronization still require real-device checks.
- Audio-preflight initialization failures retain their operation revision so the UI can accept the result and allow retry.

Make a short recording and replay before important work. The package ID remains `opencam-beta` for upgrades. Original recordings and projects are retained on uninstall. Windows/macOS recording cores are unchanged. Windows publisher signing and macOS Developer ID notarization are still not provided.
