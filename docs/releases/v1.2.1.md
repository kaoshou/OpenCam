# OpenCam v1.2.1

Windows、macOS 維持正式版本；本次新增的 **Linux 版本為 Beta**。

## Linux Beta

- 提供 x64 `.deb` 安裝版及 `.tar.gz` 免安裝版，以 Ubuntu 24.04 LTS 為主要測試目標。Linux 檔名均含 `Beta`，安裝後的應用程式名稱為 **OpenCam**。
- 安裝版透過 APT 處理相依套件，完成後從應用程式選單開啟，不用手動執行 `.sh`。歷史相容性處理：v1.2.1 修正 Ubuntu 25.04 無法安裝 ICU 74 的問題，使用該系統提供的 ICU 76；這不代表建議使用已終止支援的作業系統。
- OBS／libobs 錄影核心，使用 CPU H.264 編碼；支援 X11 螢幕／區域錄影，以及 Wayland 選擇螢幕授權、暫停續錄與來源確認。沒有新增 GDI／FFmpeg 錄影備援。
- 提供專案儲存、加入影片、剪輯、預覽、MP4／GIF／網頁播放器輸出，以及系統聲音與麥克風錄前確認。
- X11 提供虛擬教鞭、螢幕註記與可設定全域快捷鍵；Wayland **尚未提供**教鞭、桌面註記及全域快捷鍵。不同 GNOME 版本、縮放、實體音訊與長時間同步仍需實機確認。

Ubuntu 25.04 已於 2026-01-15 終止支援，不再提供一般套件與安全更新，不建議新安裝或作為正式工作環境。其他 Ubuntu 版本的相容性仍須另行確認；Ubuntu 26.04 LTS 雖仍受官方支援，OpenCam 尚未完成其安裝與錄影驗證。[Ubuntu 官方終止支援公告](https://lists.ubuntu.com/archives/ubuntu-announce/2026-January/000320.html) · [Ubuntu 官方版本生命週期](https://ubuntu.com/about)

安裝指令（主要測試目標為 Ubuntu 24.04 LTS x64，於下載檔所在目錄執行）：

```bash
sudo apt install ./OpenCam_v1.2.1_Linux_x64_Beta.deb
```

安裝後開啟 **OpenCam**。既有 Beta 套件 ID 保持 `opencam-beta`，可直接升級；移除指令為 `sudo apt remove opencam-beta`，不刪除個人錄影與專案。

## 錄影前確認

- 修正音訊初始化失敗後的狀態版本傳遞，避免介面忽略失敗結果而停留在準備中。

Linux 為 Beta，請先短錄並回放，確認畫面、音訊與輸出結果後再用於重要錄影。Windows／macOS 本次未更換錄影核心。Windows 發行者簽章與 macOS Developer ID 公證仍未提供。

## English

Windows and macOS remain the regular release. **Linux is Beta.**

- x64 `.deb` installer and `.tar.gz` archive, primarily targeting Ubuntu 24.04 LTS for testing, with **Beta** in Linux filenames. The application menu displays **OpenCam**.
- APT handles dependencies; launch from the application menu without running a shell script. Historical compatibility work: v1.2.1 allowed Ubuntu 25.04 to use its available ICU 76 instead of requiring ICU 74. This is not a recommendation to use an end-of-life operating system.
- OBS/libobs CPU H.264 recording on X11 and explicitly authorized Wayland screens, including pause/resume and source verification. No legacy recording fallback.
- Project recording, video import, editing, preview, audio preflight and MP4/GIF/Web-player export.
- X11 teaching pointers, screen annotations and configurable global shortcuts. These three desktop-integration features are **not yet available on Wayland**. Physical audio/video, scaling, GNOME-version compatibility and long-duration synchronization still require real-device checks.
- Audio-preflight initialization failures retain their operation revision so the UI can accept the result and allow retry.

Ubuntu 25.04 reached end of life on 2026-01-15 and no longer receives regular package or security updates. It is not recommended for new installations or production use. Other Ubuntu versions require separate compatibility validation. Although Ubuntu 26.04 LTS remains officially supported, OpenCam installation and recording validation on it has not been completed. [Official Ubuntu end-of-life announcement](https://lists.ubuntu.com/archives/ubuntu-announce/2026-January/000320.html) · [Official Ubuntu release lifecycle](https://ubuntu.com/about)

Before important work, make a short recording and replay it to check the picture, sound and exported output. The package ID remains `opencam-beta` for upgrades. Original recordings and projects are retained on uninstall. Windows/macOS recording cores are unchanged. Windows publisher signing and macOS Developer ID notarization are still not provided.
