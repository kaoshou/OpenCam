# OpenCam v1.3.0

本版升級至 **.NET 10 LTS**，並改善剪輯器操作與問題回報，沿用 OBS／libobs 錄影核心。提供 Windows x64、macOS Apple Silicon 與 Ubuntu x64 Beta。

本次以相同版本號更新程式包，納入剪輯與螢幕註記修正；若已下載較早的 v1.3.0，請重新下載並安裝。

## 升級至 .NET 10 LTS

- Windows、macOS 與 Linux 程式包均內附 .NET 10 LTS 執行環境，使用者無須另外安裝 .NET。
- macOS 版需 macOS 15 以上及 Apple Silicon。

## 剪輯更精確

- 新增逐格定位、片段邊界與重點標記吸附；按 Alt 可暫時略過吸附。
- 移除片段左右兩端的拖拉修剪；透過「分割 → 刪除」整理內容。拖曳片段仍可調整順序，既有剪輯範圍與原始素材保留，支援復原與重做。
- 剪輯視窗快捷鍵：Space 播放／暫停、方向鍵逐格、Shift＋方向鍵前後一秒、I／O 標記範圍。輸入欄位與控制項保留原本的按鍵操作。

## 預覽與試聽

- 快速拖曳時合併過期預覽請求，拖曳期間使用 360p、放開後恢復所選畫質；不改匯出品質。
- 播放選取範圍與循環試聽，方便確認剪接與聲音交界。
- 預覽混音音量表反映效果處理後的實際音訊，區分等待資料與無聲。已混合的系統音訊／麥克風不能事後分離。
- 儲存、預覽錯誤與最近輸出修訂分開顯示，避免將預覽失敗誤解為儲存失敗。

## 日常操作

- 改善屬性編輯期間的預覽圖片重用與背景更新安排，減少不必要的更新。
- 螢幕註記提示依實際設定顯示快捷鍵。
- 改善「操作 → 清除全部 → 橡皮擦」的畫面更新，避免重新顯示舊筆跡；補齊 Windows 操作模式的滑鼠穿透設定，保留筆跡時仍可操作底下視窗。Windows 實機驗證範圍見下方限制。
- 「設定 → 關於本程式 → 支援與診斷」可開啟日誌資料夾、複製環境資訊、匯出診斷 ZIP，以及開啟官方更新頁面。沒有自動下載或安裝更新；診斷不自動上傳。

## 下載與來源檔

一般使用者只需下載對應平台的安裝版或免安裝版。Release 的 `OpenCam_v1.3.0_CorrespondingSource.tar.gz` 是完整對應原始碼與第三方來源交付包，不是程式安裝檔；內含 OBS、Windows／macOS 媒體工具及 Linux 的原始來源封裝與驗證資料。先解壓外層，再解壓需要的元件封裝。`OpenCam_v1.3.0_SHA256SUMS.txt` 用來核對五個程式包與來源包，不需要安裝。

## 平台與驗證限制

- Linux 仍為 **Beta**，主要測試目標為 Ubuntu 24.04 LTS x64，使用 CPU 編碼。X11 提供教鞭、註記與全域快捷鍵；註記需合成器。Wayland 錄影需系統選擇螢幕授權，尚未提供這三項桌面教學整合。
- Ubuntu 25.04 的相依套件處理保留為歷史紀錄；該系統已於 2026-01-15 終止支援，不建議新安裝或作為正式工作環境。未新增其他發行版、Windows ARM64 或新的硬體加速承諾。
- 自動建置、封裝與合成測試不等於所有實體裝置已通過。效能依解析度、硬體與負載而異；重要錄影前先短錄、回放並確認匯出。長時間同步及不同桌面環境仍需實測。
- 註記清除、復原／重做、有筆跡暫停續用，以及筆跡／空白處跨程序點擊已在 Windows runner 的實際桌面驗證，並通過 Skia 畫面比對。不同實體硬體、多螢幕 DPI 與長時間使用仍需實測。
- Windows 發行者簽章與 macOS Developer ID 公證仍未提供。

## English

This release upgrades to **.NET 10 LTS** and improves editor usability and diagnostics, retaining OBS/libobs recording. Packages target Windows x64, macOS Apple Silicon and Ubuntu x64 Beta.

The application packages are refreshed under the same version to include editing and annotation fixes. If you downloaded the earlier v1.3.0 build, download and install the updated package.

### Upgrade to .NET 10 LTS

- Windows, macOS and Linux application packages include the .NET 10 LTS runtime. Users do not need to install .NET separately.
- macOS requires version 15 or later on Apple Silicon.

### Precision editing

- Frame stepping and snapping to clip boundaries/bookmarks; hold Alt to bypass snapping.
- Remove edge-drag trimming in favor of Split → Delete. Drag clips to reorder; existing edit ranges and original media remain intact, with undo and redo available.
- Editor-local shortcuts: Space plays/pauses, arrows step frames, Shift+arrows seek seconds, and I/O marks a range. Focused inputs and controls retain their own keys.

### Preview and listening

- Coalesce obsolete preview requests while scrubbing, use 360p while dragging and restore the selected quality on release. Export quality is unchanged.
- Play or repeat a selected range to check cuts and audio boundaries.
- Actual post-effect preview mix levels distinguish awaiting samples from silence. Already mixed microphone/system audio cannot be separated.
- Separate save status, preview errors and the latest export revision.

### Everyday use

- Reuse preview images and defer unnecessary background updates during property editing.
- Annotation hints follow configured shortcuts.
- Keep the drawing surface updated through Operate → Clear all → Eraser, avoiding stale ink when reopening tools. Complete Windows mouse pass-through settings so Operate mode can retain visible ink while allowing access to underlying windows. See the real-device validation limits below.
- Settings → About → Support and diagnostics opens logs, copies environment information, exports a diagnostic ZIP and opens the official update page. Updates are not automatically downloaded/installed; diagnostics are not uploaded automatically.

### Downloads and sources

Choose the installer/archive for your platform. `OpenCam_v1.3.0_CorrespondingSource.tar.gz` is the corresponding-source delivery, not an application installer. It retains original OBS, Windows/macOS media-tool and Linux source bundles and verification metadata. Extract the outer bundle, then the component archive needed. `OpenCam_v1.3.0_SHA256SUMS.txt` verifies all five binaries and the source bundle; it does not need installation.

### Platform and validation limits

- Linux remains **Beta**, primarily targeting Ubuntu 24.04 LTS x64 with CPU encoding. X11 supports teaching pointers, annotations and global shortcuts; annotations require a compositor. Wayland recording requires system screen-sharing consent and does not yet offer these three desktop integrations.
- Ubuntu 25.04 dependency work is historical; the OS reached end of life on 2026-01-15 and is not recommended for new installations or production use. No additional distributions, Windows ARM64 or new hardware-acceleration guarantees are introduced.
- Automated builds, packaging and synthetic tests do not establish acceptance on every physical device. Performance depends on hardware, resolution and load. Make a short recording, replay and check export before important work. Long-duration sync and desktop-environment coverage still need real-device testing.
- Annotation clearing, undo/redo, retained-ink pause/resume and cross-process clicks through ink and blank areas pass actual Windows runner desktop validation and Skia frame comparisons. Different physical hardware, multi-monitor DPI and long-duration use still require real-device testing.
- Windows publisher signing and macOS Developer ID notarization are not provided.
