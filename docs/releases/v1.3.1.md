# OpenCam v1.3.1

改善 MP4 匯出進度顯示，保留 v1.3.0 的錄影、剪輯與螢幕註記功能，以及內附的 .NET 10 LTS 執行環境。

## MP4 匯出進度修正

- 重新編碼期間，依實際處理影格持續更新百分比，改善長片段停在「重新編碼影片 0%」、完成時才突然跳動的情況。
- 分別顯示檢查素材、重新編碼、封裝 MP4 與驗證階段；百分比可顯示一位小數。
- 修正快速匯出改走重新編碼時，進度可能停在 90% 的情況。
- 成品通過驗證後才顯示完成；維持原始素材保護、取消清理與既有編碼品質。本次改善進度回報，不代表縮短重新編碼時間。

## 下載與平台

- Windows x64：安裝版 EXE 或免安裝版 ZIP。
- macOS Apple Silicon：DMG，需 macOS 15 以上。
- Linux x64 **Beta**：DEB 或免安裝版 TAR.GZ，主要測試目標為 Ubuntu 24.04 LTS。使用 CPU 編碼，教鞭、註記與全域快捷鍵限 X11；Wayland 錄影需系統選擇螢幕授權。
- 原始碼交付包與 SHA-256 清單供查閱來源及核對下載，不需安裝。所有程式包均內附 .NET 執行環境。
- Windows 發行者簽章與 macOS Developer ID 公證仍未提供。

## 驗證範圍

Windows、macOS 已通過實際 FFmpeg 匯出進度、取消與原始素材保全的自動回歸；Linux 已通過共用進度解析測試，新增的原生匯出案例尚未於 Linux 驗證。自動測試不代表所有實體裝置或 Linux 桌面環境已通過；重要錄影前請先短錄、回放並確認匯出。

Ubuntu 25.04 相依套件處理僅保留為歷史紀錄；該系統已於 2026-01-15 終止支援，不建議新安裝或作為正式工作環境。未新增其他 Linux 發行版、Windows ARM64 或硬體支援承諾。

## English

This patch improves MP4 export progress reporting, retaining v1.3.0 recording, editing, annotations and the bundled .NET 10 LTS runtime.

### MP4 export progress fixes

- Report actual processed frames during re-encoding, addressing long clips staying at “Re-encoding video 0%” before jumping on completion.
- Distinguish source inspection, re-encoding, MP4 packaging and verification. Percentages can show one decimal place.
- Fix progress staying at 90% when fast export falls back to re-encoding.
- Report completion only after output verification. Original-media protection, cancellation cleanup and encoding quality remain unchanged. This improves reporting, not encoding speed.

### Downloads and platforms

- Windows x64: EXE installer or portable ZIP.
- macOS Apple Silicon: DMG; macOS 15 or later required.
- Linux x64 **Beta**: DEB or portable TAR.GZ, primarily targeting Ubuntu 24.04 LTS with CPU encoding. Teaching pointers, annotations and global shortcuts require X11; Wayland recording requires system screen-sharing consent.
- Corresponding-source and SHA-256 files are for source inspection and download verification, not installation. All application packages include the .NET runtime.
- Windows publisher signing and macOS Developer ID notarization are not provided.

### Validation scope

Windows and macOS pass automated regressions using actual FFmpeg exports, progress-triggered cancellation and original-media preservation. Linux passes shared progress-parser tests; the new native-export cases have not been validated on Linux. Automated tests do not establish acceptance on every physical device or Linux desktop. Make a short recording, replay it and check export before important work.

Ubuntu 25.04 dependency work remains historical; the OS reached end of life on 2026-01-15 and is not recommended for new installations or production use. No additional Linux distributions, Windows ARM64 or hardware-support guarantees are introduced.
