# OpenCam v1.3.2

- **修復救援可直接選擇專案或資料夾。** 在主畫面選「修復救援」，可開啟 `project.opencam`、專案資料夾、舊錄影的儲存位置或單一工作階段。救援完成會保留原始 MKV。
- **縮短部分 MP4 合併匯出的時間。** 以原始品質匯出多段完整、相容的 H.264 影片時，若各段同為 16 位元整數或同為 32 位元浮點 PCM 音訊，可複製原始影像並將聲音轉為 AAC。需要精確剪接或調整解析度時，仍會重新編碼。
- Windows x64 提供安裝版與免安裝版，macOS 15 以上提供 Apple Silicon DMG。Linux x64 維持 **Beta**，主要測試目標為 Ubuntu 24.04 LTS。Wayland 需透過系統選擇螢幕授權，教鞭與桌面註記限 X11。

## English

- **Recover directly from a recording project or folder.** Open Recovery and select a `project.opencam` file, a project folder, an older recording location or an individual session. Original MKV files are retained.
- **Faster MP4 export for compatible whole clips.** At original quality, OpenCam can join complete, compatible H.264 clips with matching 16-bit integer or 32-bit float PCM audio by copying the video and encoding the audio to AAC. Precise cuts and resolution changes still use rendering.
- Downloads cover Windows x64, Apple Silicon on macOS 15 or later, and **Beta** Linux x64 targeting Ubuntu 24.04 LTS. Wayland recording requires screen selection permission. Teaching pointers and desktop annotations on Linux require X11.
