# 停止錄影快速輸出設計

日期：2026-10-09。狀態：待使用者審閱；尚未實作。

## 目的與範圍

恢復一般錄影停止後不重編碼的輸出路徑，同時保留專案、續錄與精剪功能。使用者已同意方向：未剪輯優先封裝、相容的暫停片段直接合併、有實際效果或精剪需求才轉換。不能保證所有檔案瞬間輸出；封裝、來源校驗與磁碟寫入仍與檔案大小有關。

版本維持 0.2.7，僅開發分支。不合併、不建立標籤或 Release、不觸發 Actions。先完成本機驗證，再依既有授權處理推送。此次不修改擷取或錄音引擎，不取代既有預覽控制與開啟資料夾修正。

## 現況與原因

- `RecordingContentController` 的停止流程進入 `FinishAndExportAsync`，使用 `ProjectFfmpegExporter`。
- `CopyWholeRecording` 只接受一個完整、無效果、H.264 加 AAC 的片段；無聲或多片段不符合。
- 其他情況逐段重新編碼影像、輸出 PCM，再組成 MP4。
- `ProjectOutputVerifier` 強制要求兩條串流及固定影格數，不能直接套在保留來源時間戳的無聲／可變影格率封裝結果。

## 方案取捨

採用同一匯出器內的明確策略選擇。不要另建一套不保存專案的舊錄影流程，也不要移除驗證來假裝加速。保留現有精剪輸出作為不相容素材的轉換路徑。

## 輸出決策

1. **快速封裝**：完整單一來源、無畫面效果、無裁切、無音量／淡入淡出修改，且視訊可直接放入既定 MP4 規格。H.264 視訊直接複製；AAC 音訊相容時複製；沒有音訊時不強制新增音軌。音訊格式不相容但視訊相容時，只轉換音訊，不連帶重編碼影像。
2. **快速合併**：多個完整片段按目前專案順序輸出，包括暫停、續錄及完整片段重排／刪除。必須先由實際來源確認編碼參數、尺寸、像素格式、時間基準、音軌結構及解碼初始化資料相容，且各片段可獨立解碼。僅相同 codec 名稱不代表相容。
3. **轉換輸出**：精剪範圍、畫面效果、畫布不符或合併不相容時，使用既有精確時間軸渲染。全無声片段可直接合併；有聲／無聲混合或音訊參數不一致，在無法證明安全複製時走轉換，不冒險刪除聲音。

不依「使用者有沒有開過編輯器」判斷，依實際時間軸與來源決定。策略判斷不得修改專案、來源檔或錄影參數。

## 影音與安全契約

- 快速路徑保留來源影格時間，不強迫變成設定的固定 FPS。片段間僅移除錄影暫停的空檔，保留片段內影音相對偏移。
- 合併必須處理非零起點、B-frame、音訊延遲與 AAC padding；無法維持同步時退回既有轉換。不得簡單串接 MP4 檔案位元組。
- 媒體工作仍經封閉型別與已驗證檔案 handle 執行。不得將專案提供的路徑、URL 或任意 FFmpeg 參數傳入子程序；合併所需中繼資料由程式產生並限於本次自有暫存資源。
- 保留來源 SHA、路徑／連結檢查、輸出防覆寫、取消、磁碟不足處理、暫存清理及驗證後發布。原始 MKV 與專案不因輸出失敗被刪除。
- 僅已分類的格式／時間戳不相容允許退回轉換；來源校驗失敗、取消、權限錯誤及磁碟不足必須明確失敗，不以重試轉檔掩蓋。

## 驗證分流

精剪輸出維持現有影格／取樣數的嚴格驗證。

快速輸出使用獨立契約：由驗證過的來源建立預期串流、尺寸、封包數與時間範圍；對來源及輸出做串流式封包檢查，檢查封包數、合法 DTS、PTS 範圍、總時長及各片段邊界的影音偏移。允許 B-frame 的 PTS 重排，不錯誤要求 PTS 隨封包讀取順序遞增。量化容差由來源與輸出時間基準計算，AAC 容差額外涵蓋一個 1024-sample frame，不使用固定的大容差掩蓋累積漂移。

快速路徑不再強迫每次完整解碼所有影格；保留首尾與每個合併接點的有界解碼檢查。測試套件仍對代表性輸出完整解碼，檢查內容、同步與可播放性。此為針對不同輸出語意的驗證策略，不能聲稱等同每次完整解碼掃描。

## 狀態與診斷

使用者不需選擇快速或慢速模式。進度顯示實際階段：保存錄影、整理 MP4／合併片段、轉換影片、驗證輸出。未知比例時不顯示假的百分比。日誌記錄策略、退回原因、各階段耗時、片段數及媒體參數，不記錄畫面／音訊內容。

## 驗收

- 單片段：有 AAC、無音訊、非 AAC、非零起始時間、可變影格率。直接複製影像的案例以測試攔截命令及解碼結果確認沒有呼叫視訊 encoder。
- 多片段：2、10、100 段，有聲與全無聲、重排、刪除完整片段；接點前後以測試圖樣與聲音標記核對順序及同步。
- 不相容：不同解析度、初始化資料、音軌、FPS／時間基準、精剪與效果；明確轉換，不產生損壞 MP4。
- 故障：取消、損壞來源、來源 SHA 不符、子程序失敗、磁碟不足、既有輸出同名；原始素材不變且不能發布半成品。
- 同一環境比較修改前後 1080p／30 FPS 的短片與長片，分別記錄保存、封裝／轉換、驗證與總耗時。不以單一秒數保證跨電腦效能。
- Windows 與 macOS 媒體後端均須測試。沒有 Windows 原生環境的項目標示待實機驗收，不以 macOS 通過代替。

## 完成條件

本機相關回歸測試及實際 FFmpeg 輸出檢查通過，更新使用說明與驗收紀錄，列出實測耗時及未驗證環境。普通未剪輯案例不得只因沒有音訊或多次暫停就重新編碼視訊。
