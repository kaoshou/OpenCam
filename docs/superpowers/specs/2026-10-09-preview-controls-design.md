# 編輯器預覽控制設計

狀態：待使用者確認技術補充；不是已完成功能清單。

## 目的與範圍

使用者已同意可選預覽畫質、預覽聲音開關、可調整預覽區與全螢幕，現在要求先完成再 push。
延用現有編輯器、Recorder 所有的播放器與影音同步，不另建播放器、不更改錄影與 MP4 輸出設定。
版本維持 0.2.7，只推送 codex/recording-project-persistence；不合併、不觸發 Actions、不建立 tag 或 Release。
本機編譯與測試仍是必要驗證。既有未提交驗收文件不納入此次修改。

## 現況與技術決策

目前 ProjectPreviewDecoder 與 ProjectFrameService 固定預覽為 1280×720，縮圖為 512×288。
媒體 IPC 使用 JSON/base64，最大回覆 8 MiB；1920×1080 RGBA 經 base64 後已超過此限制。
媒體解碼層的單張原始畫格上限為 64 MiB，不能將「原始畫質」解釋為無上限配置。

考慮方案：

1. 單純放大 JSON 上限：改動較少，但高解析度的多次複製與 base64 成本高，不採用。
2. 有界二進位媒體畫格：推薦。保留認證、版本與尺寸驗證，將像素自 JSON 分離，控制訊息上限不變。
3. 新增原生播放器或共享記憶體：生命週期、平台差異與安全性複雜度較高，此次不採用。

二進位畫格只使用現有專用媒體通道；協定版本、請求 nonce、generation、專案 revision、畫格尺寸與像素皆須受認證保護。
控制通道維持 1 MiB；單張像素最多 64 MiB，metadata 最多 64 KiB，驗證長度與溢位後才分配記憶體。
UI 與 Recorder 協定不相容時明確顯示需重新啟動同版本程式，不以不受驗證的舊格式回退。
串流只保留最新画格，不建立無限佇列；傳輸可取消，慢速顯示可略過過期畫格，不可讓音訊長期漂移。
停止／失去 UI 租約仍須停止聲音，停止失敗仍禁止開始錄影。

## 使用者操作

- 預覽下方整合播放、時間、畫質、顯示比例、聲音及全螢幕控制；使用 icon、工具提示與中英文文字。
- 畫質：360p、720p（預設）、1080p、原始。按專案輸出畫布等比例縮小，不為低解析度內容升頻。
- 原始指專案合成畫布像素，不是跳過裁切、縮放等剪輯效果。顯示實際像素尺寸。
- 畫布超過 64 MiB 像素限制時，停用原始選項並說明原因；仍可選其他畫質，不偷偷降級冒充原始。
- 顯示比例：符合視窗、100%、200%；放大後可平移。100% 以一個影像像素對應一個螢幕實體像素，考慮 DPI。
- 預覽／時間軸之間可拖動分隔線；預覽最小高度 160 DIP、時間軸最小高度 120 DIP。
- 全螢幕只放大同一預覽，不啟動第二個解碼或音訊輸出；Esc 返回，恢復原視窗狀態與分隔位置。
- 全螢幕控制列閒置 3 秒隱藏，指標移動或鍵盤操作時顯示；控制項有焦點時不隱藏。
- 預覽聲音只有開／關，預設開，不新增音量滑桿。聲音關閉不得改動片段音量、靜音、專案 dirty 狀態或輸出聲音。
- 這些是本次編輯視窗的檢視偏好，不寫入專案、不產生復原紀錄。

## 播放狀態與音訊

畫質切換保留 Recorder 確認的播放位置與原本播放／暫停狀態，顯示「切換畫質中」。
快速切換採最後請求優先；停止或關閉優先於重啟，舊 generation 的畫格不得回填。
載入失敗停在可重試狀態並顯示錯誤，不假裝仍播放。
靜音在輸出邊界作用於 PCM，維持取樣數與音訊時鐘；不更改 Windows／macOS 系統音量。
音訊裝置無法開啟時顯示可理解的錯誤，不能把失敗當成成功靜音播放。
Windows 使用者報告的無聲根因尚未確認；診斷包含實際輸出裝置、來源音軌與輸出錯誤。
不得因新增聲音開關就聲稱既有 Windows 無聲問題已解決。

## 元件邊界

- Core：預覽品質與尺寸計算、資源上限；不依賴平台。
- Media：按預覽尺寸解碼，保留既有剪輯效果、時間軸與音訊同步；預覽靜音不影響 export。
- Infrastructure：認證二進位媒體回覆、尺寸／長度驗證；控制 IPC 不放寬。
- Recorder：配置播放器、generation 與可取消切換；預覽／錄影互斥不變。
- UI：檢視設定、分隔線、縮放平移、全螢幕與聲音按鈕；同一個播放生命週期。

## 驗收

1. 尺寸：360p／720p／1080p／原始、直式／超寬／低解析度／超上限畫布；禁止非預期升頻。
2. IPC：真實 1080p 與 4K 畫格 round trip、竄改、截斷、錯誤尺寸、溢位、超限、取消；控制上限不變。
3. 播放：播放中與暫停中切畫質、連續快速切換、切換中停止／關閉，不得舊畫格覆蓋或殘留聲音。
4. 聲音：自建有聲影片驗證有聲 PCM／靜音 PCM／恢復聲音；專案內容與 MP4 輸出不受影響。
5. 顯示：小視窗、中英文、DPI、分隔線、100%／200% 平移、全螢幕 Esc 返回、控制列焦點可達。
6. 回歸：首頁直接錄影、停止後編輯、錄影中禁止編輯及新開專案、儲存與重開續錄。
7. 本機完整測試及可行的 macOS 自建影音驗收；記錄結果與未驗收項目。
8. Windows 真實喇叭／耳機、長時間 A/V 與不同 DPI 實機驗收標示 REQUIRES MANUAL VALIDATION，提供步驟與日誌收集方式。
