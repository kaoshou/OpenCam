# 編輯器定位與直接操作設計

狀態：歷史提案，使用者已放棄直接操控與素材插入方向；目前採用 2026-10-12-focused-editor-revision-design.md，不代表現行功能。
基準：OpenCam v0.3.1，646df8792ee720b504953de63365098bde3de2ca。

## 目的與界線

讓教材錄製者能在全螢幕定位播放，直接調整片段畫面並立即看見效果，不必先按套用。保留簡單錄影流程、原始素材、明確儲存與復原。Windows 與 macOS 使用一致操作。另統一 Windows 安裝產品名稱為 OpenCam。

使用者已同意對話中的方向；本文件具體界定跨層契約，審閱後另寫實作計畫。不在本次自動推送、合併、改版本或發布。

## 現況證據

- ProjectWorkspaceViewport.cs 全螢幕隱藏 TimelinePane；PreviewControls 無進度條。
- ProjectWorkspaceTimeline.cs Seek 依賴 CanEditTimeline；PlayheadTicks 改變時可能重新啟動有聲播放。
- ProjectWorkspaceProperties.cs 的屬性目前只是待套用欄位；HasPropertyDraft 使時間軸及預覽選項停用。
- ProjectWorkspacePlayback.cs 透過 IPC 的 ProjectId、ExpectedRevision 播放已確認版本。不能只改 UI 顯示就宣稱輸出一致。
- 安裝器 MyAppName 仍含中文；捷徑名稱已為 OpenCam。
- 現有 Crop 是每邊對稱裁切百分比（0–40），Scale 1–2，PositionX/Y -50–50。既有資料不可重新解釋為任意裁切矩形。
- 現有專案資料沒有圓角屬性；預覽容器圓角不是輸出效果。

## 一、全螢幕播放定位

一般與全螢幕共用預覽控制列、播放狀態與時間來源，不建立第二播放器。加入整個剪輯後專案的進度條及 hh:mm:ss.fff 位置输入。範圍限制為 0 到專案總長度；空專案停用。

拖曳開始記住原播放狀態，先確認既有播放與聲音停止；停止失敗不啟動另一個播放。拖曳時顯示目標時間，以最新請求優先取得靜態影格，不為每個移動啟動有聲解碼。放開後只在原先播放中時恢復有聲播放。原先暫停則維持暫停。取消拖曳恢復原位置及播放意圖。快速連續操作、跨片段、末尾定位均須有 generation 防止舊回覆覆蓋新畫面。

播放中的時鐘更新不得被解釋成使用者 seek。數值輸入驗證後才跳轉；不合法值保留原位置並就地提示。左右鍵前後 5 秒、Shift+左右鍵前後 1 秒；空白鍵播放／暫停。輸入框聚焦時不攔截文字操作。Esc 優先取消目前操作，再退出全螢幕。

控制列移動滑鼠時顯示，閒置 3 秒隱藏；游標停留、拖曳、焦點在控制列、選單開啟時不得隱藏。退出還原視窗大小、面板與焦點。沿用目前畫質及預覽靜音選項，僅觀看不造成專案 dirty。

## 二、安裝名稱

MyAppName 改為 OpenCam，保留 AppId、安裝目錄、輸出檔名規則與舊中文捷徑清理條目。安裝精靈及 Windows 已安裝應用程式產品名為 OpenCam；功能性文字如「解除安裝」可在地化，但產品名不附加中文。不改專案素材或使用者設定路徑。

## 三、直接操作與屬性面板

預設為「觀看」，保留 Fit／100%／200% 的觀看縮放。明確的「調整畫面」按鈕進入編輯模式；控制點只在此模式出現。拖動影片為位移、四角為等比例缩放，中心吸附附輔助線。觀看平移與編輯位移不能同時接收手勢。

修改選中片段前，若播放位置不在該片段，先停止播放並移到該片段有效範圍，避免調整 A 卻顯示 B。開始圖形操作時暂停，完成後維持暫停以便檢查；使用者可再播放檢查效果。

右側保留滑桿及精確數值，與控制點雙向同步。首階段維持既有縮放與位移範圍，不偷偷擴充效果語義。每項提供回預設值；「重設畫面」只改畫面效果，不改片段名稱、聲音或裁減範圍。

裁切模式呈現遮罩與控制框，明確標示「對稱裁切」。四角依既有單一 Crop 值連動，不以看似獨立的四邊控制點誤導使用者。任意不對稱裁切屬後續模型擴充，不含本版。

圓角為新增可持久化效果：預設 0；以畫面短邊比例表示半徑，范围 0–50%，UI 同時显示效果。作用於變換後影片邊界，外部使用現有輸出背景，不承諾 MP4 透明度。舊專案缺欄位按 0 載入。需同步資料驗證、編輯命令、復原、序列化、輸出指紋、複製輸出資格與各平台媒體效果，不只加 UI 圓角。

## 四、即時預覽與修改交易

取消可見的「套用」步驟。指標按下建立一次修改交易，期間只更新暫時效果；放開且合法時透過現有編輯命令提交一次，形成一筆 Undo。連續鍵盤調整在失焦／Enter 時提交一次；Esc 還原本次交易，無變更不產生紀錄。無效或未輸入完成的數值不得送到渲染器。

暫時效果預覽採 typed override，綁定 ProjectId、ExpectedRevision、ClipId 及 preview generation，只允許已驗證的效果值，不接受任意 FFmpeg 字串或來源路徑。錄影程序以既有權限及 revision 驗證解析來源，在記憶體建立暫時快照；不覆寫專案或原始 MKV、不增加永久素材。

沿用媒體效果計算建立預覽，不能對已套用效果的影格再次做同樣變換。預覽與輸出共用裁切、縮放、位置、圓角及背景順序與座標定義。拖曳期間合併請求，至多一個進行中及一個最新待處理，不排無限佇列。放開後更新使用者選定畫質的精確影格；過期回覆丟棄並釋放資源。若速度不足顯示更新中，不宣稱每台電腦均即時滿幀。

交易送出失敗保留原已確認狀態並提示，不假裝成功。切換片段、Undo、儲存、輸出或關閉前要先結束合法交易；無效輸入要求修正或取消。專案被外部變更、進入錄影、IPC 狀態不確定時取消暫時操作並安全停用編輯。

預览開關聲音仍只是觀看偏好；片段音量、靜音與淡入淡出屬剪輯效果，沿用同樣交易／合法值規則，播放採更新後快照。

## 五、儲存與資料安全

提交編輯命令只改記憶體專案與既有復原歷史，顯示未儲存。正式存檔由儲存專案操作進行；既有救援草稿可維持，但不得顯示為已儲存。Undo／Redo 一次對應一個手勢。救援草稿與正式存檔仍需明確區別。

匯出只使用已確認且儲存的編輯結果；圓角等非預設效果禁止誤走 stream-copy。原始 MKV 永不因圖形調整被覆寫或刪除。保持 IPC 認證、來源路徑驗證及輸出覆寫保護。

## 六、實作分段與驗收

1. 全螢幕定位與安裝命名：進度單一來源、拖曳停止／恢復／取消、邊界及輸入焦點測試；安裝名稱、AppId 和舊捷徑清理回歸。
2. 暫時預覽與交易：revision/generation、請求合併、取消與資源清理、每次手勢單筆 Undo、失敗回復、未儲存狀態。
3. 圖形操作與效果：DPI、黑邊／Fit／200% 座標轉換、中心吸附、對稱裁切、音訊調整；圓角舊專案相容、保存重開與精剪輸出。
4. 跨平台整合：有聲連續預覽跨片段 seek，不殘留聲音；用自建格線／角標影片在固定时间比對預覽與輸出效果，允許編碼誤差但不允許幾何不一致。取消、关闭、快速拖曳後無失控程序或持續資源增長。

Windows 與 macOS 原生互動必須分別驗收；單元測試及 CI 不能冒充兩平台實機已通過。不在未驗收時宣稱完整完成。此次不增加第三方套件、不觸碰錄製主流程或使用者未提交文件。
