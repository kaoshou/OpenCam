# OpenCam：撤回實驗功能與集中式編輯器修正

日期：2026-10-12（Asia/Taipei）
狀態：待使用者審閱；尚未開始產品程式碼修改。

## 目的與基準

使用者放棄 2026-10-11 的直接操控、即時效果、素材匯入及圖層疊加開發，只保留本文件八項需求。真正合併的語意已確認：清單與時間軸顯示為一個片段，不是群組；不先轉檔、不覆寫素材，支援復原。

- 產品基準為 `646df8792ee720b504953de63365098bde3de2ca`（0.3.1）。目前 master 的後續 `69a16ee` 僅為已取消方向的設計文件，不視為新的產品需求。
- `codex/editor-direct-manipulation` 及其未提交變更完整保留為備份，不刪除、不重設、不合併。
- 核准後由上述產品基準建立新的隔離工作目錄。原有其他文件變更不納入。
- 撤回的是昨日新增的效果實作及操作方式；不順帶刪除基準版本已存在的剪輯、屬性或錄影功能。
- 不更改版本號，不推送、不合併、不觸發 Actions、不發布 Release，除非另有授權。

## 1. Windows 安裝名稱

Inno Setup 的 AppName、必要的 UninstallDisplayName、安裝結束提示及應用程式清單名稱統一為 OpenCam。保持既有 AppId、安裝目錄與升級識別，避免多裝一份或破壞解除安裝。原本已為 OpenCam 的捷徑不改。

## 2. 僅全螢幕顯示播放進度條

- 一般編輯模式沿用既有時間軸，不新增第二條進度條。
- 全螢幕預覽底部顯示進度條、目前時間／總時間及既有播放控制。
- 拖動期間顯示目標時間；放開後定位一次，避免每個滑鼠事件都重启影音解碼。
- 原本播放中則定位後繼續播放，原本暫停則維持暫停並更新畫面。
- 拖曳、鍵盤操作或焦點位於控制區時，不讓控制列自動隱藏。離開全螢幕恢復原布局。
- 定位不改變專案剪輯內容，不產生未儲存狀態。

## 3. 片段清單群組標示

同一相鄰群組使用一致的低彩度背景、側框與「群組 N」標籤，首尾圓角形成連續區塊；不同群組可辨認。選取片段另有明確選取框，不被群組顏色覆蓋。亮色、暗色、一般與精簡列表均可辨認；不能只靠顏色傳達群組關係。

## 4. 與前／後片段真正合併

### 選擇的方式

採用非破壞性的「複合片段」。不採用群組偽裝單一片段，也不在合併時產生新的 MKV／MP4。使用者看到一個片段，內部保留依順序引用的素材區間。

### 資料與相容性

- 普通片段繼續使用原本單一來源與 InPts／OutPts；複合片段持有有序且不可再巢狀的 constituent spans。
- 每個 constituent span 保留來源 ID、精確來源時間區間及原本的音訊／画面屬性。複合片段不偽造一個不存在的素材檔案。
- 重複合併展平成單層，限制總片段／內部区間數、manifest 大小及时间基數值複雜度，沿用來源路徑及指紋驗證。
- 專案採新的明確格式版本，與昨日實驗用 schema 2 不共用語意；使用獨立 schema 3。支援讀取原 schema 1，首次需要寫入新版前備份舊專案。昨日匯入／圖層 schema 2 不自動降級、不靜默遺失內容，顯示版本不相容提示。
- 未知格式，包括草稿及備份，必須拒絕覆寫；失敗不得損害上一份可讀專案。

### 操作與屬性

- 對目前選取的單一片段與其直接相鄰片段合併，時間順序不變；首段停用向前合併，末段停用向後合併。
- 合併後採時間順序最前方片段的名稱，清單顯示合併標記及內含段數，縮圖採其起始畫面；選取與播放頭定位到新片段起點。
- 合併只改編輯配方，不新增素材，也不立即重編碼。原本不同區間的效果與聲音不能因合併消失。
- 複合片段可整體移動、改名、刪除、裁切、分割、儲存與重開；時間軸及波形呈現一個連續片段。裁切與範圍刪除按來源精確邊界映射，不用逐段四捨五入累積誤差。
- 不增加巢狀效果引擎。若內部屬性不同，屬性區顯示「多種設定」；使用者明確套用後才把所選值套用到內含區間，並可復原。不得把第一段的屬性誤顯示成全部相同。
- 有群組時，合併保留其他片段的相鄰群組規則：同群組的兩段可合併；跨群組或一方有群組時先提示「需先取消相關群組」，不隱式把整個群組吞入或拆壞。
- 一次合併為一個 undo／redo 步驟，復原完整還原兩段及其屬性。合併後存檔重開仍是一段；不承諾跨程式重啟保留完整操作歷史。

### 播放與輸出

建立共用的邏輯片段到素材區間映射：UI 使用外層片段 ID，解碼與輸出使用內部區間。連續預覽、任意 seek、音訊、縮圖、波形、精剪與快速輸出都使用同一映射。

沒有新增效果或額外裁切的合併，不能僅因外層是複合片段就強制影片重編碼；仍按展開後的實際來源與編輯條件判定 stream copy、音訊正規化或精剪輸出。

## 5. 統一離開編輯器流程

關閉視窗、左上返回、右上返回主畫面走同一個 guarded exit。若有未儲存編輯或尚未套用的屬性，提供儲存／不儲存／取消；無修改不打擾。儲存失敗或停止預覽失敗維持編輯器及鎖定狀態。取消離開不得隱藏視窗或讓主畫面恢复錄影。處理重複點擊，避免重複彈窗與重入。

## 6. 編輯器與首頁互斥

編輯器可見時禁止首頁開始／暫停／停止錄影、新建／開啟／切換專案、救援及另一筆輸出等會衝突的操作。按鈕與快捷鍵均需同一狀態守門，不能只停用 UI。IPC／錄製狀態衝突也須拒絕。只有完成安全離開，或已確認編輯視窗真正關閉後，才解除守門；保存或預覽停止失敗不能提早解鎖。

## 7. 點選片段定位

由使用者點選列表或時間軸片段時，播放頭移到該邏輯片段的開始，停止原本播放並顯示該處預覽，等候按播放。滑鼠拖曳排序、程式刷新列表、接收狀態、undo／redo 恢復選取，不當成一次使用者點選而意外跳轉。複合片段定位到最前方內部區間。

## 8. MP4 另存新檔

首頁及編輯器手動輸出均使用原生儲存檔案視窗，預填安全處理後的專案名稱與 .mp4，初始位置使用設定的輸出位置。可修改檔名與資料夾；取消不建立輸出工作。

IPC 傳遞明確目的檔案路徑，後端驗證檔案類型、父目錄、專案／素材保護與連結風險。既有檔案需使用者確認覆寫，確認後目的檔被替換或修改則拒絕並要求重新選擇，不默默覆蓋不同檔案。先寫旁側暫存檔並驗證成功，再安全交付到目的地；失敗／取消保留既有檔及錄影素材。自動停止輸出沿用既有命名與非互動流程，不要求每次停止都選路徑。

## 驗證與交付

- Core：合併順序、總長、不同時間基、跨內部邊界定位／裁切／分割／刪除、群組邊界、一次 undo／redo、格式升級與拒絕未知格式。
- Media：合併前後未調整内容的影格與音訊順序、接點及總長；preview／export 同配方；保持既有快速輸出選擇；來源檔案指紋不變。
- UI：全螢幕拖曳播放與暫停狀態、群組外觀、使用者選取和被動刷新區分、三個離開入口、儲存失敗、首頁快捷鍵互斥、另存新檔取消與覆寫。
