# 專案字幕、預覽字幕與介面修正

日期：2026-10-13。基準：OpenCam v0.3.3／5812047。狀態：設計待書面核對，尚未實作。

## 使用者目的與已確認範圍

教材作者可在編輯器附加多語字幕，直接預覽校對，隨專案攜帶並輸出離線網頁教材。字幕僅為可切換的顯示圖層，不燒入影片、不修改原始 MKV，也不影響單獨 MP4 輸出。使用者已同意聊天中提出的匯入、保存、語言辨識、樣式及預覽設計，並要求實作。

同步修正新增專案、專案改名、片段改名對話框的確認／取消文字置中，以及首頁與編輯器「輸出…」的向下箭頭。

不含字幕生成、翻譯、逐句字幕編輯、燒錄 MP4、自動重排字幕時間、額外素材插入、升版或發布。先保留既有錄影、無字幕輸出及專案流程。

## 方案與選擇

採用「專案保存原字幕檔、解析為共用 cue 資料、網頁 JS 包含資料」：一般預覽和網頁共用同一套時間解析結果；輸出仍為 index.html、media.mp4、opencam-player.js 三檔。

不採用網頁 fetch 原 SRT／VTT：file:// 的本機讀取限制會破壞離線使用。不採用燒錄：失去語言切換與關閉功能，並需重編碼。參考 evercam-subtitle-player 的語言／外觀選單概念，以 OpenCam 自有 UI 實作，不直接引入第三方播放器或依賴。

## 介面修正

- 所有上述名稱對話框的按鈕設定水平及垂直內容置中，包含 template ContentPresenter 的有效對齊；文字／圖示整體置中，不只置中 Button 本身。保持相同字級、高度及正常／hover／disabled 對比。
- 首頁和編輯器輸出選單改用現有圖示系統的向下 chevron，不使用字型字元「⌄」。統一16px圖示、線寬、間距及置中，不改 MP4／網頁選單行為。
- 編輯器輸出左側新增「附加影片字幕」圖示按鈕；窄視窗仍可到達，不擠壓其他控制項。編輯器開啟時首頁錄影鎖定機制保持。

## 字幕管理視窗

頂部提示：「字幕僅用於網頁播放器及編輯器預覽，不會燒入 MP4。可加入多種語言供觀看者選擇。」提供多檔選擇與清楚的拖放區，只接受實體 SRT／VTT 檔案。

清單每列顯示原檔名、格式、語言及解析狀態，提供語言選擇、移除和設為預設；內容過多在清單內捲動。預設字幕語言初始為繁體中文（台灣）。可取消或套用；取消不更動當前專案／草稿字幕設定，套用只加入編輯草稿，仍由儲存專案正式保存。

檔名的獨立代碼 token 不分大小寫辨識 zh-TW／zh-tw／zh_tw、en及其區域碼、ko、ja、zh-CN等；不能只在任意文字子字串找到en就視為英文。未知語言預設zh-TW，介面顯示「未辨識，請確認」。語言選項使用正規化 BCP47，提供常用語系及受驗證的自訂代碼。

同語言多份字幕不默默取代。匯入時提供替換指定既有字幕、保留兩份或取消；兩份以原檔名及序號區分，選擇軌道使用唯一ID，不能只以語言索引。替換會建立新資產，不覆寫先前的唯一實體檔。

初始預設優先選zh-TW軌道；沒有zh-TW時明確提示並採第一個有效軌道，不建立不存在的字幕。使用者已指定其他預設軌道後不因新匯入zh-TW而改掉。移除預設軌道時要求選擇另一軌或明確使用上述fallback。有字幕預設開啟，沒有字幕不顯示可用字幕選單。

## 匯入、專案保存與安全

匯入先驗證，再以不可碰撞的GUID檔名建立專案內資產，如 subtitles/<GUID>.srt 或 .vtt；原檔名僅作顯示資訊，不作實際路徑。複製使用 CreateNew 與暫存／完成流程，拒絕目錄、連結、路徑穿越、不受支援格式及來源改動。外部檔案唯讀，絕不移動或覆寫；不同語系同名亦不衝突。

每軌保存ID、原檔名、正規化語言、專案內相對路徑、格式、大小和SHA256。記錄預設軌道及附加時的時間軸簽章。重開專案只讀專案內資產，不依赖原來源位置；解析結果可重新產生，原字幕檔仍保存供後續使用。

沿用現有 edit draft、儲存／離開提示、復原／重做和recovery語意，不能把字幕匯入當成直接存檔。匯入的唯一資產可在草稿引用前存在；失敗／取消只清理此次尚未引用且可證明由本操作擁有的暫存檔。曾被專案、復原草稿或歷史引用的資產不自動刪除，避免資料遺失；首次不提供自動資產清理功能。

首次正式保存字幕設定才升專案schema為4，舊版應拒絕開啟而不能忽略字幕後保存造成遺失。無字幕的舊專案繼續使用其原schema。擴充project validation、clone、draft、歷史、save/recovery及IPC DTO時覆蓋字幕資料，不能只新增manifest欄位。字幕變更只使網頁包過期，不使未變的影音MP4成品過期或多做重編碼。

SRT與VTT共用時間cue模型，時間使用整數ticks，保留多行純文字。接受UTF-8含BOM與UTF-16 BOM；無BOM非UTF-8拒絕並說明如何另存，不能猜編碼或產生亂碼。允許有效重疊cue，顯示活動多行；忽略VTT NOTE，對不支援的樣式／標記提示，以純文字顯示，不執行HTML／JS。排序與邊界保持穩定，cue採[start,end)，不在seek時殘留上一句。

上限：每檔10MiB、最多32軌、每軌100000 cues、每cue10000字元；超限整檔拒絕並說明，不靜默截斷。結束早於開始、負時間、不可解析時間或沒有有效cue均拒絕；輸出時再核對資產大小與hash，資產缺失／改動不發布部分網頁包。

## 字幕時間與後續剪輯

字幕時間以最終影片時間軸為準。只有重新命名、音量或外觀等不改時序操作，不需提醒。裁剪、分割後刪段、排序、續錄等改變輸出內容／時長時，字幕清單與預覽顯示「時間軸已變更，請重新確認字幕同步」。

不擅自改寫字幕時間、不自動刪除字幕。網頁輸出前有未確認同步警告則讓使用者選擇仍附加輸出、此次不附加或取消；不能無聲輸出疑似失配字幕。確認同步更新基準簽章並作草稿變更。單獨MP4输出不受字幕同步警告阻擋。

## 編輯器字幕預覽

現有播放器回傳TimelineTicks／PlayheadTicks作为唯一時間來源，不另用wall clock累計。一般及全螢幕共享文字覆蓋圖層；播放、暫停、seek、點選片段、停止、切專案、播放終了即時更新／清除活動cue。字幕在畫面上疊加，不修改解碼畫格，不需要重啟或重新編碼影音。

控制列增加字幕語言／關閉選單，預覽初始選專案預設軌道，觀看時切換不改專案預設。字幕大小依可見預覽區而非720p／原始解碼尺寸；100%／200%畫面觀看及全螢幕仍保持可讀、裁切邊界與控制列避讓。

預覽外觀提供75/100/125/150/200%字級、白字黑底／黃字黑底／黑字白底／白字陰影、背景透明度、上／中／下位置及重設；立即顯示。字幕內容始終純文字。這些是本機觀看設定，不修改專案、字幕原檔或錄影片段。

## 網頁播放器字幕

opencam-player.js的OpenCamPlayerData新增可選的subtitle tracks/defaultTrackId資料，沿用安全JSON序列化、OpenCam來源註解與可被Video-to-Subtitle辨識的格式。既有schemaVersion1增加可選欄位，不移除／改義既有欄位；舊消費者可忽略新增資訊。無字幕包繼續沿用既有行為。

影片內控制列新增字幕按鈕，語言／關閉與外觀設定分層，完整鍵盤與觸控支援；選中語言明顯標示。字幕大小、樣式、透明度、位置、重設與預覽相同，觀看設定可在瀏覽器可用時記住；storage被禁用仍能播放。字幕overlay在原生或頁面內全螢幕仍顯示且避開展開控制列。

字幕資料不經fetch、eval或innerHTML；使用純文字安全DOM。共用解析後cue時間與內容，網頁只負責查詢活動cue和顯示； seek/paused/ended/切語言清除舊cue。影片本體仍由既有安全MP4管線處理，index.html最後發布，取消不損壞既有輸出與原始素材。
