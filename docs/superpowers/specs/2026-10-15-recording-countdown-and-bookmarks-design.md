# OpenCam 錄製倒數與重點標記設計

## 目的與交付範圍

讓使用者在正式錄製前有時間切換畫面，並在錄製中不必暫停就能記下重點，之後在編輯器快速定位。沿用現有錄前檢查、錄製生命週期、設定視窗與時間軸；本次不升產品版本、不打包、不推送或發布。

使用者已確認倒數、可設定快捷鍵、標記保存與編輯器定位，以及 macOS 全域重點快捷鍵。以下規格補足跨程序計時、獨立資料保存及平台註冊的整合規則。

## 使用流程

- 設定增加「錄製倒數」：關閉、3秒、5秒，預設3秒。舊設定沒有欄位時採預設值；無效值回退3秒。
- 新錄製、追加及編輯器插入錄製，完成原有名稱、保存與錄前檢查後才開始倒數。暫停後單純繼續不倒數，避免增加錄製中斷。
- 倒數顯示剩餘秒數及取消按鈕，Escape、關窗與開始／停止快捷鍵均可取消。不得建立新 session、片段或新專案；既有專案保持不變。取消與倒數結束競爭時，只能有一個結果，不能送出遲到的開始命令。
- 倒數以單調時間判斷截止，不靠累計 UI timer 次數。數字消失、視窗退出後才交回原有正式開始流程；倒數不算影片時間。倒數不發聲、不在影片上加入數字。
- 倒數期間設定與專案不可替換；完成時仍由既有 Recorder 驗證來源、狀態及擷取所有權。裝置／權限已改變或確認失效時返回檢查，不把過期確認當作有效。
- 設定增加「標記重點」組合鍵，預設 Ctrl+Shift+M；macOS 顯示相同實際修飾鍵，不把 Ctrl 誤標成 Command。沿用按鍵選單並加入 M。提供首頁「標記重點」按鈕作為替代操作。
- 僅在 Recorder 確認的 Recording 狀態新增；倒數、準備、暫停、停止、完成及試錄不新增。成功顯示不搶焦點的「已新增重點」狀態；失敗顯示原因，不能中止錄影。
- 編輯器以旗標與可捲動重點列表顯示名稱、時間，點選定位；提供改名、刪除。標記操作不分割、不裁剪、不重新編碼，也不自動產生網頁章節。

## 快捷鍵與平台整合

沿用 Core 快捷鍵抽象與 UI 命令分派，平台實作只負責註冊、解除及事件。Windows 與 macOS 均須支援程式不在前景時的重點快捷鍵；macOS 的開始／停止與暫停／繼續維持既有行為，本次不額外擴充。

Windows 現有服務回傳的是排入訊息佇列結果，不是原生 RegisterHotKey 的成功結果；同時初始訊息被預先 GetMessage 消耗。這次接線須修正註冊確認與訊息初始化，才可如實提示占用失敗。解除／結束需回收所有已註冊鍵，避免留下背景執行緒或註冊。

macOS 優先使用系統的註冊型快捷鍵 API，實作前核對本機 SDK 宣告、鍵碼與 callback ABI；不採全域鍵盤監聽、不保存一般按鍵、不為快捷鍵額外擷取使用者輸入。原生 callback 保留強引用並切回 UI 排程，不直接在 callback 執行 IPC 或磁碟工作。服務於 UI 生命週期內註冊與清理，失敗時顯示具體原因且保留按鈕操作。

設定先檢查三組快捷鍵的內部衝突，並驗證所選按鍵與修飾鍵有效。系統占用只能透過原生註冊結果確認，不能只靠設定比較。重設鍵時先檢查／嘗試新註冊，再替換舊註冊；失敗時保留舊鍵及可理解的提示，不顯示假成功。避免同一次按鍵同時被全域與前景處理兩次，忽略持續按壓的重複事件。

## 時間定位與保存

不採僅保存在 UI 的書籤：UI 異常會遺失，且累計時鐘容易混入暫停時間。不採單純專案時間座標：片段重排／插入後會指向錯誤內容。採 Recorder 保存、綁定原始錄製來源的獨立附屬資料。

專案根目錄使用固定 `opencam-bookmarks.json`，內含獨立 SchemaVersion 1、ProjectId、Revision 及標記陣列。每筆有唯一 Id、SessionId、原始錄製有效時間 offset ticks、Name；不保存使用者任意路徑。錄製時 SessionId 指向目前正式 session，Recorder 在受保護的狀態讀取當次有效錄製時間，不信任 UI 傳入時間。完成片段後依實際來源時間基準與起始 PTS 對應標記；使用現有有理數時間換算，不以浮點秒數或牆鐘猜測。

獨立附屬檔不改 `project.opencam` 與既有 schema。舊版本不提供重點操作；不可宣稱舊版本編輯或另存後一定保留標記語意。新版本開啟無附屬檔的舊專案時視為零標記，不自動寫檔。刪除此附屬檔只會失去標記，不影響影片或原有專案可讀性。

Recorder 為唯一寫入者，使用現有專案目錄綁定與原子寫入原則，拒絕符號連結／路徑穿越。標記指令包含 ProjectId、ServerInstanceId 與 operation ID，以一次操作辨識重送；重送不重複新增。每專案上限10000筆、檔案上限4MiB，名稱沿用既有名稱驗證。列表分頁、有界載入，不能在狀態輪詢中無限制傳送全部資料。

寫入成功後才回報已保存；失敗保持既有已保存標記、記錄診斷並提示，不停止錄影或觸碰 MKV。崩潰時至少保留最後一次成功的原子寫入，未確認成功的操作不保證保存。重開時資料損壞／不支援版本明示錯誤，不覆蓋成空檔；標記故障不得阻擋既有影片恢復。

標記在每個仍保留該來源位置的片段上投影成時間軸位置，重排、分割、合併、插入後重新計算；裁掉位置暫不顯示，復原剪輯可重現。相同來源位置若出現多次，列表顯示每個保留位置；改名／刪除作用於同一原始標記，畫面要保持一致。無法對應或超出實際媒體的標記保留資料並顯示未定位狀態，不猜位置、不夾到不相關片段。

標記新增自動保存；改名／刪除亦獨立保存，不加入片段剪輯 Undo／Redo。介面明示這項界線，避免「取消未保存剪輯」時誤以為會取消已保存的重點操作。

## 驗證與交付

採測試先行，先驗證缺少行為會失敗，再實作最小改動。遵從使用者簡化審查要求，不派額外審查代理，不擴大到無關錄影功能。

- 倒數：0／3／5秒、取消、關窗、到期競爭、重複開始、UI 延遲、過期狀態與來源失效；取消前後專案及 session 不新增。
- 快捷鍵：設定往返、預設、三組衝突、無效鍵、註冊失敗、重設失敗保留舊鍵、前景／全域不重複、callback／Dispose 清理。
- 標記：非錄製狀態拒絕、有效錄製時間、暫停排除、多 session、重送、寫入故障、損壞／超限檔、重開讀回及原片 hash 不變。
- 編輯器：重排、裁剪、分割、合併、插入、復原／重做、重複來源與未定位情況；可定位、改名、刪除及列表捲動。
- 執行 Release build、相關測試及完整現有測試；如有失敗如實列明，不放寬既有安全或輸出斷言。
- Windows／macOS 實機需確認背景按鍵、系統占用、功能鍵設定、多螢幕倒數不入鏡及多次重設／退出無殘留。未執行者標示 REQUIRES MANUAL VALIDATION，不以鍵碼單元測試冒稱全域註冊成功。
