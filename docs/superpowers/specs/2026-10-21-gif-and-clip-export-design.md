# GIF 與單一片段匯出設計

日期：2026-10-21（Asia/Taipei）

狀態：2026-10-21 使用者確認書面規格及滑鼠移入子選單行為。尚未實作。

## 1. 目的與已確認需求

讓使用者直接將編輯後的整部影片或單一片段匯出為 MP4／GIF，不需要另外轉檔。匯出不得修改原始錄影或專案剪輯內容。

- 整部影片的匯出選單：原本影片的「匯出…」按鈕及編輯視窗的整片匯出入口，都在既有 MP4 下方新增 GIF，保留網頁匯出。
- 片段右鍵：滑鼠移入 `匯出片段… ▶`，在旁邊展開下一階層選單，依序為 MP4、GIF。父項目不開格式選擇視窗；點選子項目才進入對應匯出流程。保留原生鍵盤子選單操作。
- 片段輸出為目前剪輯後保留範圍，套用現有畫面及音訊調整；GIF 明確排除音訊。
- GIF 不設定影片長度上限。目標範圍達 5 分鐘時警告，使用者仍可繼續。
- 選擇 GIF 後固定顯示無音訊說明，不以長度或來源是否有聲音決定是否顯示。
- GIF 寬度：480、640、960 像素、原始大小；預設 640，保持比例。
- GIF 幀率：10、15、20 FPS；預設 15 FPS。預設循環播放。
- MP4 維持既有格式與品質設定。新增 UI、警告與錯誤需支援中文／英文。
- 支援進度、取消及失敗清理。不得破壞來源、舊輸出或專案。

本次為跨 UI、IPC、匯出範圍及輸出驗證的架構延伸，不視為只修改副檔名。

## 2. 範圍定義與設計補充（隨本規格審閱）

### 整部影片

使用已保存的專案版本，依現有時間軸順序輸出所有保留片段，保留畫面裁切、縮放、位置與專案畫布。不得改用原始錄影的未剪輯長度。

### 單一片段

- 右鍵命中的邏輯片段即為目標；鍵盤開啟選單時使用目前選取片段。空白處不提供片段匯出。
- 片段清單與時間軸上可操作的片段入口採用相同命令與目標識別；不依選單開啟後任意變動的選取狀態決定輸出。
- 合併片段匯出其中全部保留子片段及效果；單純群組不擴大匯出範圍。
- 輸出從時間零開始，保留專案畫布、背景、裁切、位置與比例，不自動改成素材原始大小。
- MP4 套用原有音量、靜音、淡入淡出等音訊處理；GIF 不啟動音訊輸出或製作音訊中間檔。
- 不更改專案時間軸、片段 ID、Undo 歷史或來源檔案。內部匯出投影只存在於該次工作。
- 字幕與重點標記延續既有影片匯出語意，不新增燒入畫面、嵌入互動資訊或自動對時。

### GIF 設定的精確語意

- 寬度選項作為輸出寬度上限，不放大小於該寬度的畫面。高度依專案畫布比例計算為有效正整數；「原始大小」指專案畫布，不是某個素材的原始尺寸。
- FPS 為取樣目標，不改播放速度、不做補間。GIF 時間精度造成的影格延遲量化需按累積時間配置，不可逐影格固定四捨五入造成長片漂移。
- 循環播放固定啟用於首版，不額外增加循環次數設定。
- 設定為每次匯出的選項；首版不增加專案 schema 或全域偏好設定儲存。
- 不承諾精確檔案大小。無長度上限不代表忽略磁碟、格式尺寸、整數溢位或處理程序安全限制。

## 3. 操作流程

1. 使用者選擇整片／片段，以及 MP4／GIF。
2. 沿用未保存修改的處理流程。保存或捨棄完成後，重新確認專案、revision 與片段仍有效；取消則結束操作。
3. GIF 顯示精簡設定視窗：匯出目標名稱、長度、寬度、FPS，以及固定的無音訊說明。MP4 不顯示 GIF 設定。
4. GIF 目標長度 `>= 300 秒` 時出現確認警告；恰好五分鐘也需警告。計算依真正選定的匯出範圍，不使用整個來源檔長度。
5. 選擇輸出位置，依格式限制副檔名；錯誤副檔名不能以錯誤內容悄悄寫出。片段檔名包含安全化的片段名稱與唯一識別，沿用既有命名／避免覆寫政策。
6. 發送包含範圍與格式的明確匯出請求，顯示既有進度區與取消入口。
7. 完成轉換、驗證與必要暫存清理後才發布最終檔，提供開啟檔案／位置。任何失敗不得顯示成功。

如果對話框期間專案版本或目標片段改變，終止這次準備並提示重新操作，不悄悄改匯出別的片段。狀態不明、正在錄製或已有匯出工作等禁用條件沿用現有安全門檻。

### 文案

固定提示：

- 中文：`GIF 不包含音訊。`
- English: `GIF does not include audio.`

長度警告：

- 中文：`此 GIF 長度為 {時間}，轉換可能耗時且檔案較大。GIF 不包含音訊。是否繼續？`
- English: `This GIF is {duration} long. Conversion may take time and produce a large file. GIF does not include audio. Continue?`
- 按鈕：`取消 / 繼續匯出`、`Cancel / Continue export`。

GIF 的色彩與畫面品質可能不同於 MP4，設定區提供次要說明，不宣稱無損。長度警告每次新工作確認一次，不每個內部分段重複彈出。

## 4. 現有結構與延伸方式

已檢查的入口：

- `ProjectExportFileDialog`：目前 MP4 檔案選擇及網頁目錄選擇。
- `ProjectWorkspaceView`／`ProjectWorkspaceViewModel`：匯出選單、未保存處理、進度與取消。
- `ProjectWorkspaceListDrag.OnClipContextRequested`：現有片段右鍵與 project/revision/clip 保護。
- `ProjectIpcDispatcher`、`RecordingContentExportJob`、`IRecordingContentExporter`：匯出命令與工作生命週期。
- `ProjectRenderPlan`、`ProjectClipProjection`：已存在的半開範圍、合併片段展開與累積時間計畫。
- `ProjectExportFingerprint`：現有 MP4 輸出識別與重用。

### 請求及範圍

以明確匯出格式、整片／片段範圍、片段 ID 和 GIF 選項延伸現有請求，不增加互相衝突的布林旗標。既有請求未提供新欄位時保留既有 MP4／網頁行為；非法格式、選項、互斥組合及過期片段應在 Recorder 端拒絕。

Recorder 使用持有中的專案及已保存 revision 建立不可變匯出投影。保留原 owner／專案／revision 驗證，不能為了匯出子集合而放寬鎖定與來源存取政策。

### 輸出策略比較與選擇

1. **建議：沿用共用畫面合成／時間計畫，新增獨立 GIF 輸出及驗證。** 支援剪輯與效果一致性，避免牽動正式錄製；需補上範圍與格式化驗證。
2. 先完整匯出 MP4，再轉 GIF：可借用現有流程，但多一次編碼與磁碟耗用，且可能無謂處理音訊；不作為預設方案。
3. 直接對來源轉 GIF：較短，但難以完整保留合併片段、畫布與剪輯效果，不採用。

GIF 使用現有 FFmpeg 媒體處理邊界，不新增外部轉檔服務或應用套件。精確參數在實作計畫階段核對所打包 FFmpeg 的能力，不在本規格假稱已驗證。

編碼應採串流／有界暫存流程；禁止把整段影片影格載入記憶體，也不可採會隨影片長度無限積累待處理影格的調色盤流程。若需多趟調色盤分析，使用同一不可變範圍及可取消的重讀／磁碟暫存，不用整片 RAM 快取。

MP4 的既有快速匯出僅在選定範圍及效果符合原資格時可用；否則沿用正規渲染，不能為了快速匯出漏掉裁切或輸出片段外影格。

## 5. 安全、重用與驗證

- 所有素材讀取與暫存／發布沿用 bound-handle、owned-temporary、安全路徑及唯一命名規則；不得拼接不可信片段名稱作為 shell 命令。
- 暫存、編碼、調色盤分析及驗證各階段皆可取消；終止並等待自有子程序、關閉串流後，才能解除匯出鎖定與宣告終止狀態。
- 停止失敗或狀態不明時保留安全保護，不允許平行重複匯出。磁碟不足、寫入失敗或驗證失敗不得覆蓋既有檔案。
- 清理只刪除該工作擁有的暫存檔，保留來源與既有輸出。最終檔只在驗證成功後發布。
- 輸出指紋包含格式／profile、有效匯出內容、畫布和 GIF 寬度／FPS／循環政策。不得把整片 MP4、片段 MP4 與 GIF 誤認為同一輸出；舊 MP4 receipt 保留原匹配語意。
- GIF 驗證包含可完整解碼、有效尺寸、非空畫面、無音訊、循環資訊，以及按累積取樣時間計算的合理總時長。不能只驗檔案存在或第一張圖。
- 時間驗證依格式量化制定可解釋邊界，不能為了讓測試通過任意增加容忍值。輸出不得包含所選片段範圍外的影格。
- 不設定與整片長度無關的固定短轉換期限；沿用取消及卡死監測設計，並對格式能力／資源失敗給出可理解的錯誤。

## 6. 驗收與回歸

功能測試：

- 整片選單順序、片段右鍵子選單、中英文、鍵盤入口、空白處與無效狀態禁用。
- 普通片段、已裁短片段、合併片段與群組內片段；確認只輸出正確範圍，不修改專案及來源。
- 畫面裁切／位置／縮放／背景與編輯器一致；片段 MP4 音量／靜音／淡入淡出維持現有語意。
- GIF 設定預設與全部可選值、奇數比例、小畫布不放大、原始畫布大小。
- 警告邊界：低於五分鐘、剛好五分鐘、高於五分鐘；整片長但選定片段短時不誤警告。取消警告不啟動轉換，繼續不受硬性時長上限阻擋。
- GIF 永遠顯示無音訊提示且輸出無音訊；10／15／20 FPS 的累積播放時間不因取整而線性漂移。

可靠性測試：

- 過期 revision、選單期間刪除片段、重複請求、非法格式／參數、路徑替換及特殊檔名。
- 各處理階段取消／程序失敗／輸出損毀／磁碟不足，確保無假成功、無殘留自有子程序、無來源或舊檔損失。
- 指紋不混用不同格式／範圍／GIF 選項；原 MP4、網頁與自動停止後匯出回歸。
- 使用真正合成影片驗證首尾內容、不同素材邊界、畫面效果、完整解碼和 GIF 時間資訊；不以字串參數比對取代媒體驗證。
- 長片記憶體有界性與取消反應列入實測，不宣稱固定轉換耗時或預估檔案大小。

Windows 與 macOS 使用實際打包版本驗證匯出及常用檢視器播放。未執行的原生／人工驗收明確標示待驗證，不用本機 synthetic 結果代替。

## 7. 不在本次範圍

不增加 APNG／WebP、GIF 錄製模式、批次匯出、多選片段匯出、任意時間範圍選取、字幕燒入、互動重點、編碼器偏好或自動發布。

不處理其他 CI 根因或新效能重構。既有發布排程維持停用；本規格不授權推送、發布或改變版本號。
