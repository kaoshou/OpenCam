# 播放器導覽與可後製指標設計

狀態：完整設計及高效能擷取限定的架構調整已獲使用者確認（2026-10-24）。版本不在本次實作中調整。

## 目的與範圍

閱讀設定改為小型文字揭露按鈕；改善播放器鍵盤導覽與說明。新增 Windows/macOS 可後製指標：使用者錄影時正常使用系統滑鼠，影片來源不擷取原生游標，另記錄位置，預覽與輸出才合成教鞭或其他樣式。使用者已選擇此方案，重點是錄影後可以更換指標。

不改正式錄影的音訊、編碼器選擇、恢復與來源所有權保護。不移除既有安全驗證，不在此工作合併或發布。使用者另已允許推送開發分支，使用獨立工作流程驗證 Windows 原生模組；不得部署網站或發布 Release。舊影片不提供去除已燒入游標的功能。

## 方案取捨

1. 桌面浮窗教鞭：目前方式；操作畫面也會出現教鞭，錄進原始影片後無法更換，不符合使用者選擇。
2. 錄影即時合成：可讓操作桌面保留正常游標，但增加即時處理負擔且成品不可更換，未採用。
3. 無游標畫面加時間同步軌跡：使用者已選定；減少錄影中的裝飾繪製，將成本移到預覽／輸出。需新增格式、軌跡驗證與編輯時間映射。

## 播放器介面

- 「▶ 閱讀設定」為靠右小型文字按鈕，展開為向下箭頭；保留足夠觸控範圍、可見焦點與 aria-expanded。既有浮動設定面板保留，預設內容仍只顯示語言與搜尋等既有基本操作，進階選項不佔逐字稿高度。
- 鍵盤說明改分組：頁面導覽、播放控制、分頁操作、設定視窗。每列呈現適用焦點位置、按鍵與作用；窄螢幕堆疊、不橫向溢出。
- 增加可用 Tab 到達的「跳至播放器／章節／逐字稿」導覽；啟動後實際移動焦點，必要時退出寬螢幕側欄隱藏狀態並切換分頁。沒有字幕時清楚表示無逐字稿，不能跳到隱藏元件。
- 保留焦點限定的單字母快捷鍵，不攔截搜尋輸入、選單和滑桿原生按鍵；可透過鍵盤回到播放器操作。逐一驗證現有控制項，不把快捷鍵作用範圍擴成全頁。
- 參考 https://accessibility.moda.gov.tw/Accessible/Guide/68 的鍵盤操作、無鍵盤陷阱、快捷鍵、跳過區塊、焦點順序與焦點可見要求；報告實際驗證範圍，不宣稱取得無障礙認證。

## 錄影與指標設定

- 新增明確的「可後製指標」錄製方式，先採使用者主動選用；保留現有錄製方式供舊專案與不需後製者使用，不默默改寫既有偏好。
- 使用者確認第一階段限定高效能擷取：Windows 新增自有 WGC 原生模組，macOS 擴充現有 ScreenCaptureKit 模組。一般 GDI／桌面擷取／macOS 一般擷取維持既有行為，不提供可後製指標。新模式必須關閉輸出影像中的原生游標；桌面系統游標不隱藏、不更換，也不啟動既有教鞭浮窗。
- 捕捉的是所選錄影範圍內的位置、可見狀態與必要的按鍵狀態，絕不記錄鍵盤輸入或視窗文字。範圍外只記錄不可見，不保存範圍外座標。
- macOS 第一版以一般桌面操作為範圍：使用者已接受錄影範圍內顯示後製指標，不保證跟隨遊戲或其他軟體自動隱藏游標。不得用已停用的游標可見性 API 假稱完整偵測；設定及使用說明須交代限制，編輯時仍可隱藏後製指標。
- 一個來源分段一份軌跡；暫停停止該段，恢復建立新段。錄影來源切換、DPI 或螢幕拓撲改變須沿用既有範圍有效性檢查，不能將座標套到錯誤螢幕。
- 軌跡收集失敗不能讓無指標影片假裝完整：錄影前無法準備時，明確提供一般錄影選擇；錄影中軌跡失效時保留影片並標記軌跡不完整，不能悄悄將原生游標燒入同一段。

## 編輯與樣式

- 在「編輯錄製內容」新增指標設定區；第一版採整個專案共用樣式，可選細長教鞭、標準箭頭、光點、隱藏，提供大小與還原預設。單一片段獨立樣式、外部圖片匯入留待後續。
- 教鞭參考使用者圖片，以透明、細銀色棒身與短黑色握柄重新繪製，不直接使用含雜點的圖片。預設全長約 56 個 1080p 輸出像素、棒身約 3 像素，大小範圍 50–200%；這些為實作者提案，可在視覺核對時微調。
- 每個樣式明確定義尖端／中心熱點；教鞭與箭頭尖端定位，光點中心定位。縮放後熱點保持不動；樣式在預覽、MP4、GIF、網頁播放器的 MP4 一致。
- 含軌跡來源可以換樣式；舊來源若游標已燒入，只顯示「此片段未記錄可編輯指標」，不得疊出第二個指標。混合專案按來源能力處理。
- 樣式更動納入既有保存／復原／重做與匯出內容指紋，防止沿用舊匯出結果。

## 資料與時間同步

- 使用專案持有的旁車軌跡檔，記錄來源 ID、捕捉範圍、座標轉換版本、時間基準與樣本。來源使用大小及 SHA256 綁定，讀取沿用 bound handle 與相對路徑保護；不把外部路徑直接傳入媒體程序。
- 新軌跡專案升為 schema 5；舊 schema 1/3/4 保持可讀，僅使用新功能時升級，舊程式應拒絕新格式而非錯誤匯出。備份須包含整個專案及軌跡檔。字幕、複合片段、草稿、復原與 schema 升級規則一併更新，不能把版本降回 4。
- 滑鼠單調時鐘時間必須對應來源影片 PTS；不能直接把第一個 progress 回報抵達的時間當第一幀時間。先以合成定位事件驗證時鐘橋接，再決定平台實作；若某擷取路徑無法建立可信映射，明確不提供可後製模式，不能以固定啟動延遲冒充同步。
- 建議以最高 120 Hz 有界採樣／事件合併方式收集位置，按鍵與可見性轉換不得被合併丟失；持續串流寫入，不讓檔案與記憶體隨錄影長度無限堆積在 RAM。實作前量測平台開銷並訂明容量限制與失效行為。
- 以來源 PTS 查詢軌跡，沿用 ProjectRenderPlan 的片段裁切、重排與複合片段時間；先套來源裁切／縮放／位置，再套輸出畫布與預覽縮放。多螢幕負座標、Windows DPI、Mac Retina／Y 軸轉換須具可驗證映射。
- 相鄰有效樣本可線性插值；不跨暫停、不可見、拓撲改變或大於 100ms 的缺口插值。缺口不外推，不把最後位置永久留在畫面；點擊事件不因平滑而延後。
- 軌跡檔採可恢復的分塊／完整記錄邊界，異常退出只恢復已驗證前綴。檔案不存在、損壞或對不上來源時，預覽提示，要求套用指標的匯出停止並讓使用者明確選擇不含指標匯出。

## 合成與效能

- 在既有預覽／匯出共用合成流程加入指標層，不在 UI 自行畫一套而讓成品不同。字幕與章節仍維持既有行為；指標受影片畫布裁切，不蓋到播放器控制列。
- 合成器須逐幀、可取消、有界緩衝；避免為整段軌跡建立巨大 FFmpeg 表達式或整段透明影像存入記憶體。具體媒體輸入方式由實作者先做受控原型比較後選定。
- 有可見後製指標時不能使用略過指標合成的快速串流複製匯出；隱藏或沒有軌跡的情況保留可用快速路徑。
- 確認輸出尺寸與裁切後位置、影格數、音訊時間、取消與磁碟不足的行為；指標失敗不能留下看似完成的正式輸出檔。

## 驗證與交付

- 第一階段：播放器小按鈕、說明與焦點導覽；桌機、手機、平板、放大、鍵盤、閱讀設定開關與匯出閱讀稿回歸，附合成內容截圖。
- 第二階段：時鐘與軌跡的受控原型；驗證靜止、快速移動、點擊、啟停、暫停、跨範圍、負座標與 Retina。比較錄影開銷與預覽／匯出成本，量測定位誤差，目標不超過一個輸出影格；若達不到須回報原因並調整設計。
- 第三階段：持久化、編輯控制、共用合成；裁切、複製、重排、複合片段、混合舊來源、縮小輸出、所有匯出格式、損壞軌跡、恢復與取消回歸。
- 中／英／日文字同步；網站與指南說明新錄影才有可更換指標、操作桌面保留正常游標，以及預覽／輸出的設定位置。
- 平台實機未驗證部分如實標記，不能以合成測試宣稱 Windows/macOS 實機通過。完成後提供畫面與測試結果；發布另依使用者指示。

## 留給實作者的決策

檔案編碼、分塊尺寸、平台事件 API、共用合成器的媒體傳遞方法與樣式繪圖細節由實作者依測試選擇；不得改變以上使用者操作、所有權、安全、時間一致性及舊專案限制。若時鐘橋接需更換擷取架構或新增重大依賴，先回報具體證據及取捨。
