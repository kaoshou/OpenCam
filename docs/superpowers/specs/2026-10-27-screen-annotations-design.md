# 螢幕註記：確認的設計

在主程序內加入可拆除元件，不新增程序，不變動 OBS、影音時間軸、專案格式或輸出。
設定「啟用螢幕註記工具」預設開啟，但未按入口不建立視窗，不自動攔截輸入。
Windows/macOS 共用模型、畫布與工具列，平台適配只負責透明覆蓋視窗與穿透。

## 範圍

- 畫筆、直線、箭頭、方框、橢圓，顏色與三種粗細。
- 整筆移除、清除全部、復原/重做；不支援文字、局部切斷或區域裁切。
- 註記模式：滑鼠移動只指示；左鍵按住才畫，放開完成一筆。
- 游標樣式、教鞭大小和尖端熱點不因繪圖工具改變，不建立第二支教鞭。
- Esc 返回操作模式，筆跡保留，畫布穿透；工具列仍可點選。
- 註記直接錄入影片，事後不可移除；固定螢幕位置，不隨教材捲動。
- 僅錄製範圍內接受筆畫；失去擷取、切換工具、暫停時取消未完成筆畫。
- 暫停隱藏並保留；同範圍續錄恢復為操作模式；停止/變更範圍清除並關閉。
- 關閉/停用/故障只關閉註記，不發送錄影、音訊或輸出命令。
- 靜止時無繪圖計時器；筆畫和歷史紀錄有明確上限。
- 工具列美觀可拖動/收合，三語、鍵盤可用。先不承諾工具列完全不入鏡。

## 架構選擇

已比較獨立程序和主程序內元件。使用者明確選擇後者：降低額外啟停與通訊成本，
代價是無法隔離整個 UI 程序崩潰。畫布文件與視窗控制器不參考錄影服務；
接點僅為設定、主畫面入口、當前錄影範圍及狀態。

## 驗收限制

自動測試、實際視窗互動及實機錄製分別記錄；無 Windows 實體桌面時不得宣稱驗收通過。
不改版號、不合併、不推送、不發布；交付開發分支與驗證狀態。
