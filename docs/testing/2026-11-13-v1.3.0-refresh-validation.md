## 本次程式與說明

- .NET 10 LTS 為版本更新重點：SDK 10.0.404，程式包內附 runtime 10.0.15，使用者無須另外安裝 .NET；macOS 需 15 以上與 Apple Silicon。
- 移除時間軸兩端拖拉修剪，改用分割／刪除；保留既有剪輯範圍、歷史相容性與原始媒體。
- Windows 操作模式使用獨立原生透明筆跡視窗，繪圖模式使用 Avalonia 視窗；兩者都在同一程式程序內。避免 CS_OWNDC 與 WS_EX_LAYERED 不相容，並讓有筆跡時仍能操作底下程式。
- 清除後選橡皮擦不再重開舊繪圖緩衝區；macOS／X11 保留繪圖表面更新，Windows 重新建立繪圖 HWND 並共用同一筆跡文件與復原歷史。
- OBS／libobs 錄影核心未更換，未新增 GDI／FFmpeg 錄影 fallback。

## 保留限制

不同實體硬體、多螢幕 DPI、音源熱插拔、休眠恢復及 4／8 小時長時間驗證尚未完成，不宣稱全部裝置已通過。Linux 維持 Beta，以 Ubuntu 24.04 LTS x64 為主要測試目標；25.04 僅保留歷史相容性紀錄，不建議新安裝。Wayland 與實體 GNOME 驗證限制維持原說明。

同版號更新不會讓舊版 1.3.0 自動辨識為新版本；先前已下載者應重新下載並安裝本次程式包。
