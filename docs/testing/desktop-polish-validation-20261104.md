# 剪輯、教學操作與支援介面：本機驗證

日期：2026-11-04（臺灣時間）。基準：`1e12ff769b0e7863798fe5063f9b9930d1bc34fa`；開發期間唯讀確認遠端 master 仍為相同提交。

## 本輪內容

- 播放／拖曳預覽時不啟動新的背景縮圖、波形請求。波形優先選取及可見片段；快取最多 256 筆，滿載後仍可載入晚段可見片段，不持續重建離屏波形。
- 同尺寸預覽重用 WriteableBitmap，更新像素後明確使 Image 失效重繪；尺寸改變時才換緩衝。原有輸入焦點、改名、舊回覆丟棄及拖曳續播行為均保留。
- 註記工具列的提示／無障礙名稱帶入實際可用的自訂快捷鍵，更新提示不重建按鈕、不刪筆跡。初始位置依實際工具列高度約束，保留原有隱藏／收合及尺寸還原機制。
- 「設定 → 關於本程式」及獨立關於視窗增加支援區：檢查更新、開啟日誌資料夾、複製環境資訊、匯出診斷資料。Enter 不再無條件關閉獨立關於視窗，讓焦點按鈕可正常操作，Esc 仍可關閉。
- 檢查更新僅開啟官方 Releases；不自動查詢、下載或安裝。診斷匯出須由使用者選擇新 ZIP 檔名，禁止覆寫，不自動上傳。
- ZIP 只收集環境摘要及最近四個日期的 `app-yyyyMMdd.log`，每檔最多 2 MiB。透過已開啟的目錄與安全檔案控制代碼拒絕連結及非一般檔案；允許唯讀存取正在寫入的 Windows 日誌，既有讀檔呼叫的預設共享規則不變。
- 環境摘要包含四類剪輯器 IPC 往返耗時的次數、平均與最大值，不含命令參數、片段名稱或路徑；它不是擷取 FPS、解碼吞吐或端到端播放效能。
- 繁中、英文、日文介面均提供說明；新增繁中與英文使用手冊段落。無新增第三方依賴，版本仍為 1.2.1 開發中程式碼。

## 回歸與審查紀錄

新增案例先重現：拖曳仍啟動背景工作、可見波形沒有優先權、256 筆快取滿後晚段不再載入；修正後通過。位圖測試驗證同尺寸物件重用、不同尺寸換緩衝及實際更新的像素。原有文字輸入焦點、游標位置、改名不清空預覽的案例持續通過。

獨立唯讀審查未發現 Critical，發現一項 Important：安全讀檔拒絕硬連結時會拋出 `InvalidDataException`，不是 `IOException`，導致整包取消。新增跨平台硬連結測試確實失敗後，補上逐檔略過；再次測試確認正常日誌及環境摘要仍匯出，來源檔不變。亦涵蓋最近日期白名單、過大日誌、Unix 符號連結、正在寫入的日誌、既有目的檔與取消清理。

第一輪完整測試為 Core 384、Media 1,601 通過。審查修正後的下一輪出現既有 `PreflightAudioCaptureTests.StoppedCaptureCannotReadLevels` 立即音量斷言失敗（取得 .2 暫代值）；相同二進位檔不更動重跑三次皆通過。程式碼確認啟動 acknowledgement 等待正值 `out_time_us`，音量 astats 解析為非同步；測試已在原有 15 秒期限內等待暫代值被取代，保留原來 .06–.065 精確音量與停止後讀取斷言。沒有更動正式音訊流程。其後相關 84 項及最終全套均通過，未將先前失敗隱藏為略過。

## 實作取捨

1. 沿用既有非 master 開發目錄，逐檔提交本輪變更；避免搬動或覆蓋原有 GNOME 工作，代價是需嚴格限制提交範圍。
2. 超過 2 MiB 的日誌整檔略過而不截尾；明確提示，代價是大型日誌需另行人工提供。
3. 手動前往版本頁，而非網路版本比對或自動更新器；代價是使用者自行比較版本。
4. 無像素的 headless stub 不能驗證像素持續性，另用實際 Skia 檢查；代價是需該測試環境。
5. 設定入口在錄影／暫停時不可開啟，因此保留 ShowToolbar／SetMode／語言變更時更新提示；將來若允許即時改設定，需另接通知。
6. 原生對話框、剪貼簿、瀏覽器、資料夾與混合 DPI 不以自動化結果代替實機驗收；代價是交付後仍需平台實測。
7. 原有 GNOME 原型、擷取核心與實驗性 Wayland 功能不納入；本輪不擴大 Wayland 教學功能承諾。
8. 只同步既有測試的非同步音量觀測，不改正式聲音／錄影行為；代價是一項測試範圍外的小幅測試維護。

無具體 Minor 審查項目被擱置。

## 未驗證及下一輪人工驗收

- Windows／Linux 實機安裝、原生存檔取消、剪貼簿、預設瀏覽器與檔案管理員整合。
- 實體雙螢幕不同解析度／縮放下，多次移動及隱藏工具列，快捷鍵實際註冊與其他應用程式焦點互動。
- 長時間真實課程的剪輯流暢度與記憶體變化；300 片段排程測試不等於真實長影片效能評測。
- 新安裝包在內附 Runtime 的測試，以及擷取／音畫同步／Wayland 實機驗收；本輪未變更這些核心，也不宣稱已重新驗收。
- 分享診斷前檢查 ZIP：沒有收集媒體檔，但日誌文字仍可能包含檔案路徑、裝置名稱及私人內容，不是匿名化檔案。
