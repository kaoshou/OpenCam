OpenCam 0.4.1 — macOS Apple Silicon 新核心專用測試版（非正式 Release）

適用 Apple Silicon（M 系列）及 macOS 13 以上，不適用 Intel Mac。
完整解壓縮後開啟 OpenCam.app；不要覆蓋舊版本或修改 App 內檔案。
不需要安裝 OBS Studio 或 .NET。此包未經 Apple 公證；若系統阻擋，
請在確認來源後，到「系統設定 → 隱私權與安全性」選擇「仍要打開」。
不要關閉系統安全防護。若測試包放在下載資料夾無法開啟，可先移到獨立資料夾再試。

只包含 libobs 新螢幕錄影核心，透過 ScreenCaptureKit 擷取。
舊一般擷取設定會自動忽略，不會切回舊核心。音訊試聽、剪輯及匯出仍保留 FFmpeg。
首次使用請允許螢幕錄影；需要錄麥克風時也請允許麥克風權限。
權限調整後若仍無法擷取，完全結束 App 後再開啟。

首次開啟預設 20 FPS；既有使用者儲存的 FPS 保留。
建議先用 20 FPS、標準畫質、編碼器「自動」，選擇單一螢幕及需要的音源。
也可改用 CPU 編碼；不需要硬體影片編碼器，但 CPU 效能、解析度和背景程式會影響流暢度。
不要將此實機測試包用於唯一一次的重要錄影。

請建立新錄影專案，先錄 30–60 秒：靜止畫面開始、移動教鞭、播放有聲動態影片。
停止後檢查編輯器預覽及匯出的 MP4：確認不是黑畫面、有聲音、聲畫同步、教鞭清楚。
再測試暫停／繼續、5 分鐘錄影，並比較 CPU 編碼與自動編碼。
舊專案仍可剪輯與匯出，但不要用此包繼續舊核心建立的工作階段。

若失敗，停止並保留整個專案，不要刪除 MKV 原始素材。
請回報：Mac 型號、macOS 版本、FPS、解析度、編碼器、音源，以及預覽與 MP4 是否相同。
在 Finder「前往 → 前往檔案夾」輸入 ~/Library/Application Support/ScreenRecorder/Logs，
附上測試當天 app-日期.log。不需要提供私人錄影或聲音。
日誌中的 "RecordingCore":"libobs-v1" 可核對新核心；請保留原始錯誤及 Recording native startup 段落。

自動化驗證包含生成畫面與音訊的時鐘同步、CPU／Apple 編碼、停止與異常中斷安全性。
這不等於已完成你那台 Mac 的實際螢幕、麥克風及系統音訊驗收。
