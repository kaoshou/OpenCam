OpenCam 1.0.0 — Windows 錄影核心測試版（非正式 Release）

完整解壓縮到新的資料夾，再執行 OpenCam.exe。不要覆蓋舊版本或修改 obs-runtime 內的檔案。
此包只包含 libobs 新螢幕錄影核心，不包含舊 FFmpeg 螢幕錄影引擎或 OpenCam.ScreenCapture.exe。
新核心無法啟動時會停止並回報，不會改用 GDI；正式版未變更。FFmpeg 保留給聲音試聽、剪輯及匯出。
不需要安裝 OBS Studio，也不需要另裝 .NET。

設定：
1. 設定 → 畫面擷取只有自動。舊 GDI／桌面擷取設定不會生效，不需要刪除設定檔。
2. 首次開啟預設 20 FPS；已儲存的其他 FPS 保留。先用 20 FPS、標準畫質、編碼器自動，選擇要錄的單一螢幕；需要時再比較 30 FPS。
3. 音源依需求開啟，先用短片確認，再測試較長內容；暫勿用於唯一一次的重要錄影。
4. 舊核心建立的專案仍可剪輯與匯出，但不能在本包繼續錄製舊工作階段；請建立新錄影專案。

建議測試：
本包調整 Windows 系統聲音靜音時的啟動與持續擷取；保留 libobs/WGC，未加入舊錄影核心備援。
系統音訊沿用預檢的「預設多媒體輸出」端點。錄影中切換預設輸出或移除裝置會回報並保留工作檔，請停止確認後重新開始。
開始前不用播放任何聲音。分別測試「雙音源但系統靜音」、「僅系統聲音且靜音」、「僅麥克風」、「不錄音」。
錄製中播放、停止、再播放聲音，確認靜音時不出現音源異常，聲音恢復後仍正常收錄。
預檢取消後重試、F10 多次暫停續錄、首次開始失敗後重試，也請檢查。
先錄 30–60 秒：靜止畫面開始、移動教鞭、播放有聲動態影片，停止後檢查預覽與匯出 MP4。
再測試 5 分鐘，以及暫停／繼續；確認開始、中間與結尾的音畫同步與畫面是否流暢。
若出現黑畫面、沒有聲音或錯誤，先停止並保留整個專案，不要刪除 MKV。

請回報：
使用的 FPS、編碼器、音源、擷取範圍，卡頓／音畫秒差是否改善，預覽與 MP4 是否相同。
檔案總管輸入 %LOCALAPPDATA%\ScreenRecorder\Logs，附上測試當天 app-日期.log。
不需要上傳私人錄影或聲音。日誌中的 "RecordingCore":"libobs-v1" 可確認實際使用新核心；
啟動失敗時請提供 "Recording native startup" 及錯誤碼附近的紀錄，內含畫面尺寸、音源是否就緒與啟動階段。
移除舊核心不代表所有實體電腦的啟動問題已解決；本包不會以假影格、假音訊或放寬期限掩蓋失敗。

原生核心需要 Microsoft Visual C++ x64 執行階段；若缺少，請從 Microsoft 官方安裝，
不要從其他網站下載個別 DLL。未能啟用新核心時不會假稱新核心測試成功。
這是實機驗收包；自動測試通過不等於此電腦已完成長時間錄影驗收。
不需要獨立顯示卡或硬體影片編碼器，CPU 編碼仍需正常的 Windows 圖形驅動與桌面環境。
不同 CPU、解析度及同時執行的程式會影響流暢度，不保證所有電腦都能達到 1080p／30 FPS。
