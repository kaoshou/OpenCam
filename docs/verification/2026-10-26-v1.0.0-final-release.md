## Publication identity and tooling

With explicit user approval, the previously unpublished `v1.0.0` tag was
changed from `989f920a6dc54e5472b86f4af6f846e32aebcb09` to the verified
application commit above. Its original target is preserved as
`archive/v1.0.0-initial-20260916`. No existing Release asset was overwritten.

An owned draft's public by-tag API returned HTTP 404 during publication.
The uploader now resolves the draft through `gh release view`, validates the
repository-scoped numeric API identity, then verifies immutable SHA-256 after
upload. Live SOURCE-INDEX upload and identical-byte retry passed. Replacement
of differing bytes remains prohibited. This publishing-tool change does not
change the tagged application or the verified binary artifacts.

All nine uploaded assets matched their local size and SHA-256. The Release
became public on 2026-10-26 at 04:00:28 UTC; all three binary download URLs
returned HTTP 200 before advancing the website download manifest to 1.0.0.
The final script/player/CI suite passed 116 / 2 skipped / zero failures with
normal desktop access. Its initial sandbox run aborted the unchanged AppKit
initialization fixture; the identical suite passed outside that restriction.

## Limits

Automated native/synthetic checks, full decoding and package verification do
not establish physical WGC/WASAPI behavior on every GPU/audio device, subjective
sound quality, or multi-minute real-hardware synchronization. User-reported
manual acceptance is separate evidence. Unperformed device hot-plug, every
resolution/FPS combination and exhaustive endurance tests are not claimed as
passed. Windows binaries are unsigned; macOS is ad-hoc signed, not notarized.
