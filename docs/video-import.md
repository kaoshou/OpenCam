# 加入外部影片

此功能自 OpenCam v1.2.0 提供。下方保留開發驗證的實際紀錄，不等同所有裝置與格式均已人工驗證。

## 使用方式

1. 開啟錄製專案，進入「編輯錄製內容」。空白專案也可加入影片。
2. 按左側片段區「加入影片」，可選擇多個檔案；也可從檔案總管／Finder 拖入左側片段區。
3. 等候檢查、加入或轉換及驗證完成。可按「取消」停止目前工作及剩餘排程。
4. 成功的影片加入時間軸結尾，使用原檔名命名。可重新排序、分割、修剪、合併、調整音量與輸出。

多檔依檔案選取器／拖放提供的順序逐一處理。單一檔案失敗不撤銷已成功的影片，最後會列出失敗項目。匯入期間暫停編輯及新錄影操作，狀態查詢及取消仍可使用。

## 素材與格式

- 輸入範圍為 MP4／M4V、MOV、MKV／WebM、AVI；實際可用性取決於隨程式附帶的解碼器。
- 目前接受單一影片軌及零或一條音軌。多音軌會提示先另存單音軌版本，避免默默選錯語言。內嵌字幕及章節不自動匯入，可另用既有 SRT／VTT 流程附加字幕。
- PQ／HLG HDR 影片及寬高超過 4096 像素的影片目前拒絕加入，避免未處理的顏色／輸出差異。
- 相容的 H.264、YUV420P、方形像素、無旋轉影片優先重新封裝；必要時轉為軟體 H.264，非 AAC 音訊則轉為 AAC。程式不要求獨立顯示卡。轉換可能花費時間並改變畫質或大小。
- 專案保留原本畫布及 FPS，預覽和輸出沿用既有等比例縮放及補黑邊流程。
- 整理後的 MKV 儲存在專案 `sources/`，外部原影片只讀取、不修改。成功匯入後不再依賴原始位置。
- 提交前完成整段解碼、現有預覽路徑的首幀與音訊讀取，以及素材雜湊。這些檢查能發現解碼失敗，但不代表已由人工看完、聽完內容。
- 每次成功匯入可復原／重做；復原移除時間軸片段，保留專案素材。若素材已完成發布但後續專案儲存失敗，仍保留該素材供救援。
- 原有字幕與章節沿用既有同步確認機制；重新排序或剪輯後應檢查時間。此版不新增自動字幕對時。

## 實作範圍

`ProjectVideoImporter` 使用現有 Windows／macOS bound-file 媒體後端；`ProjectImportedMedia` 管理暫存與發布；錄影程序的協調器管理背景工作、取消及原子專案提交。MCP、AI、OBS 擷取與錄影引擎均不需要變動。

## 人工驗收清單

以下為 REQUIRES MANUAL VALIDATION，不包含在上述通過數字中：

- Windows 安裝／免安裝成品、實際檔案選取及拖放：空專案與既有錄影片段各加入 MP4／MOV，確認名稱、預覽、聲音、匯出、復原與重開；收集 app 日誌及輸出媒體資訊。
- macOS 實際 Finder 拖放與使用者自有影片：確認權限、視窗操作及主觀播放聽感；保留日誌。媒體後端自動化通過不能替代此項。
- 長影片及磁碟空間不足：預留空間不足時應拒絕且原檔／專案不變；轉換中磁碟耗盡應明確失敗、保留原素材。測試專用磁碟或受控資料夾，不使用重要素材。
- 非固定 FPS、HEVC、WebM／AVI、多音軌與 HDR 真實樣本：確認支援者可預覽與輸出，不支援者有清楚提示；目前未逐一驗證所有編碼組合。
- 字幕與章節專案：加入後檢查既有同步提示，重新排序後確認不會無提示地使用錯位字幕。
